# 工艺规范 v0

全库通用、与风格无关的细节精度规则（方案 3.1「工」），各设计体系只调参数，不改规则。读法：每条规则都有「规则 / 理由 / 适用边界 / 检查」四项。
- 检查为「自动」的，给出检查器规则标识（`类别/名称`）；阈值只在 rule-data 键所指的 `src/checker/rule-data.ts` 条目，或体系令牌（`--ds-*`）里，本文不重复数值。
- 检查为「人工把关」的，检查器不判断，由 agent 自查、裁判复核。
- 本文与检查器的对应由 `test/craft-doc.test.ts` 保证：文中引用的规则标识必须存在，注册的每条规则必须被引用。新增或改名检查规则时同步改本文。

## 材：质感底线

### 材-1 不用纯黑纯白
- **规则**：文字、背景、边框、阴影的颜色里不出现 #000 和 #fff；黑取偏暖或偏冷的深色，白取带色温的纸色或亮色，由材质锚点推出。
- **理由**：纯黑纯白在任何真实材质里都不存在，它们是「没有设计过」的默认值，最先暴露廉价感。
- **适用边界**：只看不透明的颜色，透明度为 0 的 rgba 不算。摄影图片内部的像素不在检查范围。
- **检查**：自动 `texture-floor/pure-black-white`。

### 材-2 灰要带色相
- **规则**：中性灰向体系的色温偏一点，不用不带色相的灰。
- **理由**：不带色相的灰在暖色或冷色环境里显得发死，像贴上去的。
- **适用边界**：只查明度在中段的颜色；极深极浅的颜色由材-1 管。体系刻意做黑白灰单色时，在体系说明里写明并取偏色而不是零色度。
- **检查**：自动 `texture-floor/hueless-gray`，阈值见 rule-data 键 `texture-floor/hueless-gray`。

### 材-3 阴影方向与光源一致
- **规则**：同一体系只有一个光源方向，所有有偏移的阴影都顺着它。
- **理由**：阴影方向不一致，眼睛会立刻觉得这些元素不在同一个物理世界。
- **适用边界**：偏移很小的阴影（接近纯模糊）不判方向。体系声明为无光源的材质（如纯平面印刷）不使用阴影。
- **检查**：自动 `texture-floor/shadow-direction`，容差与最小偏移见 rule-data 键 `texture-floor/shadow-direction`。

### 材-4 阴影带环境色
- **规则**：阴影用环境色或材质色加透明度，层数与软硬由材质决定，不用纯黑半透明。
- **理由**：真实阴影是环境光被遮挡后的颜色，不是黑色蒙一层。
- **适用边界**：硬边印刷类材质可用实色偏移，但颜色仍取体系色。
- **检查**：人工把关（取色是否来自体系由值-1 兜底，是否带环境色要看成品）。

### 材-5 隐喻，不模仿
- **规则**：材质靠光、色温、颗粒、边缘和运动体现；颗粒与噪点不超过体系声明的上限，不贴写实木纹、皮革等贴图，除非体系意图明确需要。
- **理由**：照搬材质外观容易沦为拟物装饰；近看经得起推敲的是一致的光与边缘处理。
- **适用边界**：体系的意图写明需要写实材质时可以例外，并要在体系里写出理由。
- **检查**：人工把关。

## 工：排版与细节

### 工-1 按视觉效果对齐
- **规则**：对齐按眼睛看到的边缘，不按盒子坐标。大字标题、引号、圆形与三角形等形状的光学重心与边缘要手动补偿；图标与文字并排时按视觉中线对齐。
- **理由**：数学对齐在字形有留白、形状有曲率时看起来是歪的。
- **适用边界**：正文段落与表格按数学对齐即可，补偿只用在大字号、孤立的图形和图标上。
- **检查**：人工把关。

### 工-2 字距随字号调整
- **规则**：大号展示字收紧字距，小字放开字距；正文保持字体默认。数值写进体系的字阶，作品里不临时调。
- **理由**：字体的默认间距是为正文字号设计的，放大后字距显得松，缩小后显得挤。
- **适用边界**：汉字方块字距本来均匀，大标题只需轻微收紧；全大写西文与小型大写字母要放开。
- **检查**：人工把关。

### 工-3 中文标点挤压
- **规则**：全角标点连排或处在行首、行尾时按 clreq 的规则挤压，不留下半个字宽的空洞；标题与大字号文本尤其要处理。
- **理由**：全角标点自带一个字宽的占位，不挤压会在字行里出现空洞，拉低整齐度。
- **适用边界**：浏览器不支持挤压的载体，用字体的标点宽度特性或在体系里改用更合适的字体；正文小字号影响不明显，可放宽。
- **检查**：人工把关（行首行尾的合法性由工-5 自动查）。

### 工-4 中西文间距
- **规则**：汉字与西文字母、数字相邻时留出间距。
- **理由**：不留间距时两种文字挤成一团，行内节奏不均。
- **适用边界**：构建步骤会自动加间距，与检查器共用同一个定义；手写的自定义片段要自己遵守。标点与西文之间不加。
- **检查**：自动 `cjk-typography/missing-spacing`。

### 工-5 避头尾
- **规则**：行首不出现句号、逗号、右括号等禁止行首的标点，行尾不出现左括号、左引号等禁止行尾的标点。
- **理由**：标点悬在行首或行尾，会破坏一行的视觉边界，是中文排版中最容易被看出的失误。
- **适用边界**：破折号与省略号属严格级别，只给警告。宽度不确定的响应式文本以检查器渲染结果为准。
- **检查**：自动 `cjk-typography/line-start-forbidden`、`cjk-typography/line-end-forbidden`。

### 工-6 不留孤字
- **规则**：段落最后一行不只剩一个汉字（末尾标点不计）。
- **理由**：孤字让段落收尾显得草率，也浪费一行的垂直空间。
- **适用边界**：只查两行及以上的段落。可通过改字、调整宽度或换行平衡处理，不靠加空格撑开。
- **检查**：自动 `cjk-typography/orphan-line`。

### 工-7 圆角嵌套
- **规则**：嵌套的圆角，外圆角 = 内圆角 + 内边距（含边框）。
- **理由**：外层圆角比内层小或相等时，两条弧线之间的间隙不均匀，转角处会显得挤或松。
- **适用边界**：只查子元素贴在父元素圆角处的情形；子元素不在转角附近或父元素无圆角时不适用。
- **检查**：自动 `texture-floor/radius-nesting`，容差见 rule-data 键 `texture-floor/radius-nesting`。

### 工-8 图标线宽与字重匹配
- **规则**：图标的线宽与相邻文字的字重视觉上相当；同一套图标线宽统一，端点与转角样式统一。
- **理由**：线宽比文字笔画细或粗很多，图标会显得像另一套体系里来的。
- **适用边界**：大尺寸的插图式图标不受此限；描边风格的整体选择属于体系的画风。
- **检查**：人工把关。

### 工-9 数字字形按场景选择
- **规则**：表格、价格、数据、计时等需要纵向对齐或会变化的数字，用等宽（tabular）字形；正文与标题里的叙述性数字可用老式（oldstyle）字形或比例字形。同一处不混用。
- **理由**：等宽数字保证列对齐、数值变化时不抖动；老式数字融入正文，不突兀。
- **适用边界**：字体不提供对应字形特性时，改用字体本身的等宽数字，不用别的字体拼凑。
- **检查**：人工把关。

## 值与色

### 值-1 取值合规
- **规则**：颜色、字号、间距、圆角都取自体系声明的值，不自造数值。
- **理由**：成套的比例关系是体系设计感的来源，临时数值会破坏节奏。
- **适用边界**：0 与布局关键字（auto、normal）不算自造；允许少量浮点误差，具体宽容度见规则实现。纯黑纯白交给材-1，不重复报。
- **检查**：自动 `value-compliance/color`、`value-compliance/font-size`、`value-compliance/spacing`、`value-compliance/radius`，值来自体系令牌。

### 值-2 对比度
- **规则**：文字与背景的对比度达到 WCAG 2 AA；文字压在图片或渐变上时，先保证有稳定的底（遮罩、纯色块），再请人确认。
- **理由**：看不清的文字是最基本的失败，且在远处看的幻灯片与信息流配图里更严重。
- **适用边界**：检查器无法计算图上文字，只给警告，必须人工确认。纯装饰、不承载信息的文字例外。
- **检查**：自动 `contrast/insufficient`；`contrast/text-over-image` 只提示，结果由人工把关确认。

## 构图

### 构图-1 三个比率落在体系声明的范围内
- **规则**：跳跃率、版面率、图版率都落在体系为该载体声明的范围内。
- **理由**：这三个比率决定了节奏与气质，是感觉词落到设计决定的坐标。
- **适用边界**：只测首屏或当前画面（网页的第一屏、一页幻灯片、整张配图）；声明范围由体系给，不同载体不同。只给警告，作品概念需要时可以有理由地突破。
- **检查**：自动 `composition/jump-rate`、`composition/layout-rate`、`composition/image-rate`，松弛量见 rule-data 键 `composition`。

## 动效底线

### 动效-1 时长与缓动取自体系
- **规则**：动画的时长在体系的时长阶梯内，缓动在体系的缓动集内。
- **理由**：统一的时长与缓动是「手感」的载体；随手写的数值会让动静不同源。
- **适用边界**：只查网页与幻灯片上能被检查器采集到的动画；社交配图没有动效。
- **检查**：自动 `motion/duration-off-ladder`、`motion/easing-off-set`，阶梯与缓动集来自体系令牌（`--ds-duration-*`、`--ds-easing-*`）。

### 动效-2 只动 transform 和 opacity
- **规则**：动画默认只改变 transform 与 opacity。
- **理由**：这两个属性可以由合成器处理，不触发布局与重绘，动起来才不卡。
- **适用边界**：translate、rotate、scale 视为 transform。确需改变其他属性时，应在体系里写明并附理由，不在作品里临时用。
- **检查**：自动 `motion/non-compositor-property`。

### 动效-3 尊重减少动态效果
- **规则**：系统开启「减少动态效果」时，去掉位移类动画，只保留透明度变化或静止。
- **理由**：位移与缩放会让对前庭敏感的人不适，这是可访问性的底线。
- **适用边界**：只约束 transform 类；仅改变 opacity 的淡入淡出可以保留。
- **检查**：自动 `motion/transform-under-reduced-motion`。

### 动效-4 目的、预算与高光
- **规则**：每条动效规则标明目的（反馈、导向、层级、叙事）；每件作品只有一两处高光时刻，其余保持安静。
- **理由**：说不出目的的动效是噪音；到处都动等于没有重点。
- **适用边界**：交互反馈这类小动效不计入高光预算，但仍要有目的。
- **检查**：人工把关。

## 字体

### 字体-1 字体来自字体清单
- **规则**：作品里实际显示字形的字体，都在库的字体清单里。
- **理由**：清单之外的字体（含系统回退字体）没有核对过授权与字形，也无法保证各端一致。
- **适用边界**：清单见 `library/fonts/manifest.json`；中文无衬线等回退链要在清单内写全，不依赖系统字体。
- **检查**：自动 `fonts/not-in-manifest`。

### 字体-2 字形覆盖完整
- **规则**：作品中每个字符，清单里被使用的字体都有这个字形。
- **理由**：缺字会回退到别的字体或显示成方框，是最明显的粗糙。
- **适用边界**：看字体内部的字符映射表，而不是文件名。需要生僻字或符号时，换字体或在清单里加一个覆盖它的字体。
- **检查**：自动 `fonts/missing-glyph`。

### 字体-3 授权对应载体
- **规则**：作品使用的字体，其授权允许用在当前载体上。
- **理由**：网页、幻灯片、社交配图的授权条款不同，用错载体有法律风险。
- **适用边界**：以清单里的载体标注为准；授权条款本身的变化需要人工复查清单。
- **检查**：自动 `fonts/license-carrier`。

## 防同质化

### 同质-1 相邻单元不用同一种排法
- **规则**：作品里相邻的两个叙事单元，不使用同一种排法。
- **理由**：连着重复同一个版式，页面就像模板填空，节奏出不来。
- **适用边界**：自定义片段会打断相邻关系；社交配图只有一个单元，不触发。
- **检查**：自动 `anti-homogeneity/adjacent-same-layout`。

### 同质-2 不堆等大卡片
- **规则**：不把三个及以上尺寸相同、结构相同的块排成一行当作默认版式；用主次、错位和留白区分内容。
- **理由**：等大卡片网格是最典型的模板味，把本该有主次的内容压平了。
- **适用边界**：只有内容本身确实平等（如一组同类型的徽标或数据项）时才可用，并在作品里说明理由。只给警告。
- **检查**：自动 `anti-homogeneity/equal-card-grid`。

## 做减法

### 减-1 交付前先删
- **规则**：交付前过一遍：删掉可有可无的文字，删掉与别处重复的规则、线条和装饰，删掉没有承担作用的容器层。删完再看一遍，确认没有因删减丢掉必要信息。
- **理由**：细节精度的最后一步是克制；「一屏只有一个主角」要靠删出来。
- **适用边界**：不删可访问性所需的文字与语义结构；用户明确要求的内容不删。
- **检查**：人工把关。
