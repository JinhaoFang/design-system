# 标准样张设定：苇简 Reedslip 2.0

标准样张的内容底稿。内容虚构，与设计领域无关，不偏袒任何体系。共享内容（`web.json`、`slides.json`、`social.json`）中的事实、数字和人物都以本文件为准。

## 名称

- 中文名：苇简。取「苇编为简」之意，一份笔记就是一枚轻薄的简牍。
- 拉丁名：Reedslip。
- 官网（虚构）：reedslip.example。
- 查重：检索「Reedslip」「苇简」未发现同名软件，npm 上也没有同名包。

## 它是什么

开源、本地优先的 Markdown 笔记软件，以 MPL-2.0 协议发布。笔记就是用户文件夹里的普通 `.md` 文件，软件只负责编辑、检索、同步和扩展。支持 macOS、Windows、Linux 和 Android。2021 年起由一支 6 人核心团队和社区贡献者维护，累计 312 位开发者贡献过代码。

## 给谁用

手里有几千到几万条笔记、不愿被某个软件锁住资料的人：研究者、工程师、写作者、学生。他们的共同点是笔记会攒很多年，而且需要在两三台设备之间同步。

## 2.0 改了什么

1. 搜索：重建本地全文索引，只更新改动的部分。3 万条笔记的平均搜索延迟从 1,290 毫秒降到 86 毫秒，约快 15 倍。
2. 同步：从整文件覆盖改为按段落合并。每千次同步弹出的冲突提示从 14 次降到 0.3 次，离线编辑两周的改动也能无损合并。同步仍是端到端加密。
3. 插件：插件接口 v1 稳定，带版本号和权限声明，2.x 内不做破坏性改动。已有 38 个社区插件完成迁移。
4. 启动：冷启动从 2.8 秒降到 0.9 秒。
5. 长笔记：打开 10 MB 的长笔记只需 0.4 秒，滚动保持流畅。
6. 导入：可导入其他笔记软件导出的 Markdown 和 HTML 文件。

## 数字口径
