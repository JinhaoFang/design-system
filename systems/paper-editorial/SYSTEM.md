# 纸本编辑

一页刻印好的书：暖白哑光纸，墨色印字，校书人用朱笔在最要紧的一句下面画了一道。

## 意图

**为谁。** 给有内容、有来历、值得慢慢看的项目：文化机构、科研团队、出版与研究成果、地方与手艺。观看者愿意停下来读，想知道「这件事是怎么回事」，而不是被催着点按钮。

**传达什么。** 可信、从容、有分寸。页面像一份认真编过的文献：事实准确，层级分明，没有一处多余的热闹。第一眼不必惊艳，第十眼仍然舒服。

**调性位置。** 静 2 · 疏 2 · 暖 4 · 轻 2 · 庄 2。安静但不呆板：朱笔是唯一被允许「动一下」的地方；端庄但不冷：楷书批注带着人的手迹。

**不适合。** 需要强促销、倒计时、密集数据看板、科技感的场合。硬要用，纸本编辑会显得迟缓；换精密工业或孔版印刷。

**关键规则。**

1. **一屏（一页、一张）只有一个主角。**
   - 理由：纸本的庄重来自取舍。主角越少，读者越信任编者的判断。
   - 适用边界：任何载体都成立。网页长页按「屏」计，一屏是一个视口高度。
2. **朱色只用于批注、印章和朱笔下划线，合计不超过画面的 6%。**
   - 理由：朱是校书人的笔，不是装饰色。用多了，「批」就变成了「涂」。
   - 适用边界：任何载体都成立。图像里的朱色星标、印泥也算进预算。
3. **正文不居中，不两端撑满成方块之外的形状。** 正文左对齐、两端对齐（`text-align: justify`），短题、题签、印章可以居中。
   - 理由：刻本的正文是满栏排的，参差的右边会让纸面显得潦草；整段居中则读不下去。
   - 适用边界：正文超过两行时成立。一两行的引语、落款可以居中或右对齐。

## 材质锚点

**暖白哑光纸上的油墨印刷，朱笔批校。**

| 方面 | 推出什么 |
| --- | --- |
| 光 | 案头的漫射光，从左上来（135°），很软。纸张只在被「抬起」时投影：投影向右下、半径大、带墨色的暖褐，不用纯黑半透明。平铺的纸面没有投影 |
| 表面 | 哑光，不反光，没有高光和渐变。纸面有极淡的纤维颗粒（强度上限 0.05），用纸色的深浅而不是灰色来表现 |
| 边缘 | 印刷线：版框是一粗一细的双线（文武边栏），界栏是发丝线。直角，不倒圆角；唯一的圆角是 2px 的发丝圆角，只给票券、标签这类小件 |
| 色温 | 纸偏暖白（OKLCH 色相约 85°），墨偏暖黑，所有灰都是「淡墨」，带同一个色相。不用纯黑纯白 |
| 图像处理 | 像印在同一张纸上：单色墨线、雕版或工程图的笔法，朱色只点在要紧处。照片要做成单色暖调、压低对比，像铜版印刷 |
| 手感 | 纸：被手推着滑入，带一点摩擦，停住，不回弹。墨：先淡后浓地洇出来。印章：按下去，稍大一点落定。朱笔：起笔慢、行笔快、收笔轻 |

## 视觉语言

### 色彩

三种材料就是三组颜色：纸、墨、朱。

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| `paper` | `#f1ebdf` | 底色，所有载体的纸面 |
| `paper-light` | `#f6f1e6` | 抬起来的一张纸：票券、夹页 |
| `paper-deep` / `paper-shade` | `#e8dfcd` / `#ddd2bc` | 衬纸、色块分区、星图底盘 |
| `ink` | `#1f1a14` | 标题、正文、版框粗线 |
| `ink-2` | `#4f483d` | 次要文字、说明 |
| `ink-3` | `#6e6656` | 页眉页脚、刻度、编号 |
| `ink-shade` | `ink` 的 12% 不透明度 | 幻灯片翻页时，蒙在后退的上一页上的暗影 |
| `rule` / `rule-light` | `#b9ae99` / `#d6ccb8` | 界栏、发丝线、分隔线 |
| `zhu` | `#b23a26` | 朱批、印章、朱笔下划线 |

- **墨色分三级，不另造灰。**
  - 理由：刻本上的深浅来自墨的浓淡，三级足够表达层级；多一级就像软件界面。
  - 适用边界：任何载体都成立。`ink-3` 在 `paper-deep` 上对比度只有 4.3，只用于 24px 以上的字或纯装饰的刻度。
- **整页不出现第二种彩色。** 图像里需要区分类别时，用墨色的实线、虚线、点线，不加颜色。

### 字体

#### 中文搭配

- **宋体排字，楷书批注。** 正文、标题都用思源宋体（Noto Serif SC）；朱批、落款、手写感的一句用霞鹜文楷（LXGW WenKai）。宋体是「印」出来的，楷书是「写」上去的，两者的关系就是印本与批校的关系。
  - 理由：同一页上只有两种中文字体，一种代表文献，一种代表人，读者一眼就分得清哪句是正文、哪句是编者的话。
  - 适用边界：任何载体都成立。楷书每屏不超过两处，单处不超过一句话。
- **字重拉开，而不是字号拉开。** 大标题用宋体最细的 200（ExtraLight），正文 400，小标题 600。大字越细越像刻本的扉页，小字略重才站得住。
  - 理由：纸本的「轻」靠细笔画的大字，而不是粗黑大标题。
  - 适用边界：幻灯片远看时，标题不低于 `title` 档字号才用 200；更小的标题改用 400。
- **字距随字号走。** 竖排题签和六字以内的短大字放开（0.08–0.14em，竖排题签可到 0.2em）；横排多字的大标题收到 -0.01–0.02em；正文 0，小字（`caption`、`note`）放开到 0.08–0.16em。
  - 理由：短大字和竖排题签靠字间的空气显得疏朗；横排长标题再放开字距，一行就散成一个个孤立的字，读不成句（工艺规范工-2：大号展示字收紧）。
  - 适用边界：`display` 档以上、横排超过六字的标题按收紧处理；竖排不论字数都按放开处理。

#### 中西文混排

- 西文与数字用 Source Serif 4，与思源宋体同为衬线、笔画对比相近。正文字体栈西文在前（`font.body`），这样数字和拉丁字母自动落在 Source Serif 上。
- 数字按场景选字形：正文里用旧式数字（`onum`），表格、日期、价格用等高等宽数字（`lnum` + `tnum`），超大数字用 Source Serif 300 的等高数字。
- 单位、学名、拉丁名用 Source Serif 斜体，例如 *m*、*Andromeda*。
- 中西文之间留间距（构建时自动补），中文标点挤压，避头尾按工艺规范。

### 版面

**构图比率。** 跳跃率高、版面率低、图版率中低：大字很大、留白很多，图像只在需要时出现。

| 载体 | 跳跃率 | 版面率 | 图版率 |
| --- | --- | --- | --- |
| 社交配图 | 2.5–10 | 0.12–0.60 | 0–0.55 |
| HTML 幻灯片 | 2–10 | 0.10–0.60 | 0–0.65 |
| 展示型网页（首屏） | 3–10 | 0.12–0.50 | 0–0.55 |

**版框与版心。** 宋元刻本的一页有固定的结构：四周版框（文武边栏，一粗一细），中间一条版心（标书名、卷次，上下有鱼尾）。本体系的画面以此为骨架：

- 版框只用于「封面性」的画面（扉页、封面、社交配图的题签型，幻灯片的题签封面、题语页和收尾的牌记页），不给每一屏都套框。
- 版心是可选的竖条，在双页结构里把画面一分为二。
- 界栏（行间发丝线）用于需要逐行核对的信息：清单、时间表、参数。

**横竖排的适用边界。**

- **竖排只用于标题、题签和装饰性的短文本**（单处不超过 16 字）。
  - 理由：竖排是刻本最有辨识度的特征，但现代读者竖读长文很慢。
  - 适用边界：任何载体都成立。
- **需要扫读、核对的信息一律横排**：日期、场次、价格、规则、门票、清单、数据。
  - 理由：这些信息是拿来查的，横排配等宽数字才能一眼对齐。
  - 适用边界：任何载体都成立，没有例外。

**节奏。** 两三段安静的阅读之后，来一次满版的高潮（一张大图、一句大字、一个大数字）。相邻的叙事单元不用同一种排法。

| 图片 | `tuban` 图版 | 一块四周留纸、带压印线框的图版，进页时向上揭去衬纸，图下一行图注 |
| 图片 | `banye` 半页 | 图占右边大半页、进页时向右揭去衬纸，左边一栏图说，栏顶墨线与鱼尾 |
| 结尾 | `yinzhang` 印章 | 结束语整句下一道朱笔（宽度随句子），右下一枚朱印写着行动号召 |

- **一册里朱笔不超过两页，且不相邻。** 排法里带朱笔的只有 `damu` 和 `yinzhang`，作品里再加上作品概念的高光页；通常一道给高光页，一道给结尾一句。关键数字已经有朱笔页在旁边时，改用不带朱笔的 `chizhu`。
  - 理由：朱笔下划线是高光时刻，连着几页都有，读者就不再把它当成高光。
  - 适用边界：只管幻灯片整册。单页仍按「一页最多一次」。
- **竖向网格。** 页眉墨线在上；主体落在视觉中心（约 45% 高度）附近，或有意压到下半页（`jishi`、`piyu`、`rizhi` 的基线），不留「没排完」的空。分卷页和大数页上半的留白是有意的疏。
- **远看的字号。** 除页眉、页脚、出处以外，正文和说明不小于 `body` 档（32px）。
- 除图片单元外，十个单元的排法都不依赖图片；没有图时，图片页换成 `chizhu` 或 `damu` 这类以数字撑画面的排法。

竖排的题签（`tiqian` 的标题、`yuanqi` 的小标题）要求文字不超过 16 字，更长的内容换同单元的另一种排法。手机宽度（860px 以下）一律单栏：竖排题签改横排放在段首，跨页去掉版心，图版放到文字之后；`tiqian` 的标题在手机上仍竖排，因为它是整屏唯一的主角。

**网页的整页节奏。**

- **两三段安静的阅读之后，来一次满版的高潮。** 安静段是正文、录表、年表这类只有文字和界栏的段；高潮是一屏满版的图版（衬纸色出血）、一句 head 档以上的大字引语，或一个 title 档的大数字。首屏本身算一次高潮，所以第一次满版最早出现在第三或第四段。
  - 理由：刻本翻几页文字才见一幅插图，图才显得珍贵；每段都抢眼，读者就不知道该看哪里。
  - 适用边界：长页（六段以上）成立。三四段的短页只要首屏和行动号召两处高潮。
- **段与段之间不画分隔线，靠留白和衬纸分段。** 段落上下留白用 `space-9`（手机同为 `space-9`），满版图版用 paper-deep 衬纸与前后分开；需要「另起一卷」的感觉时，用段首的一道墨线（`fenlan`、`yinkuan`）或文武线，不用通栏的灰色分隔条。
  - 理由：纸本的段落感来自版心里的空白和换页，一道道横线会让页面像表单。
  - 适用边界：任何网页成立。页脚可以用衬纸色收底。
- **内容栏宽 1240px，左右留 `space-8`（手机 `space-5`）；正文栏收到 21–30 字。** 宽栏只给图版、年表和标尺，正文永远是窄栏。
  - 理由：中文正文一行超过三十字就难以换行回读；宽版面靠留白和页边札记撑开，而不是把正文拉长。
  - 适用边界：正文超过两行时成立；短导语、图注不受限。
- **卷次自动编号。** 正文各段（问题、方案、特性、证据、流程）按出现顺序自动编为壹、贰、叁…，写在段题签或段号里；首屏、行动号召、页脚和定制片段不占卷次。
  - 理由：卷次让一张长页读起来像一卷有次序的书，也替读者记住读到了哪里。
  - 适用边界：只用于网页。卷次是朱色楷书时，算进这一屏的楷书和朱色预算。
- **相邻的段不用同一种排法，竖排题签不连续出现两段。** 一段竖排题签之后，下一段换成横排小标题。
  - 理由：同一种排法连着出现就像模板填空；竖排太多会拖慢阅读。
  - 适用边界：任何网页成立。

### 形态

- 直角。唯一的圆角是 `hair`（社交配图 3px、网页 2px），只给票券、标签、按钮这类小件。
- 线有三种：版框粗线（墨，2–3px）、版框细线和界栏（`rule`，1px）、朱笔下划线（朱，手绘曲线，粗 4–8px，两端收细）。
- 印章是方形朱底、纸色阳文楷字，边缘略毛（只用于印章本身）。
- 不用卡片、不用胶囊按钮、不用图标库。需要符号时用鱼尾、圈点（○ ●）、刻度。

### 图像与画风

- **画风：单色墨线的图版。** 像刻本插图或旧天文图集里的铜版图：墨色细线、点描表现明暗，没有渐变和色块阴影。朱色只点一两处（被指认的星、注释的箭头）。
- **优先画「图解」而不是「场景」。** 星图、仪器剖面、等高线、月相历、路线图，是本体系最有力的图像：它们本身就是文献。需要人物和场景时（如观测夜的访客），用线描，人物不画五官细节，靠姿态和红光的位置讲故事。
- **素材来源。** 图解（星图、等高线、剖面、标识）用代码绘制（SVG），生成脚本放在本体系的 `images/src/`，用真实坐标和数据（星表、口径、路线里程）。人物和真实场景的光影用代码画会僵硬，改用生图模型，提示词按上述画风写成配方（`images/src/prompts/`），成品是同一种铜版蚀刻的墨调。要加标注、朱笔或动效时，用代码叠在图上。不用图库照片。
- **图像在画面里的位置。** 图像是一块「图版」：四周留纸，配图注（图号 + 一句说明，`caption` 字号），不出血、不铺满。只有满版高潮那一屏可以出血。

#### 无图方案

没有图像时，用三样东西撑起画面：竖排的大字题签、文武边栏的版框、朱印。大字用 200 字重放到 `display` 档以上，四周留出至少三成的纸面。数据型的画面用超大的细衬线数字代替图像。

### 识别符号

- 朱笔下划线：一道手绘的朱色笔画，只画在全屏最关键的半句话下面
- 文武边栏：一粗一细的双线版框，用于扉页、封面和题签
- 朱印：方形朱底阳文的印章，落款、品牌、行动号召只用它

## 动效语言

**性格：纸与墨。** 纸被推着滑入，带一点摩擦停住，不回弹；墨先淡后浓地洇出来；印章按下去落定。动效是「翻书」而不是「变魔术」：东西从它在纸上该在的位置出现，不飞、不转、不缩放（印章的一次落定除外）。

| 时长 | 数值（基准 40ms） | 用在 | 目的 |
| --- | --- | --- | --- |
| `dot` | 160ms | 悬停、按下的反馈 | 反馈 |
| `turn` | 280ms | 印章落定、小件切换 | 反馈、导向 |
| `ink` | 480ms | 文字洇出（透明度） | 层级 |
| `glide` | 800ms | 纸张滑入、翻页 | 导向 |
| `lift` | 1200ms | 拂去衬纸、朱笔划过 | 叙事与情绪 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `paper` | `cubic-bezier(.2, .65, .15, 1)` | 位移：纸张滑入、翻页，前快后慢，带摩擦停住 |
| `ink` | `cubic-bezier(.4, 0, .2, 1)` | 透明度：墨色洇出 |
| `press` | `cubic-bezier(.3, .8, .3, 1)` | 印章按下落定 |
| `brush` | `cubic-bezier(.6, .05, .3, 1)` | 朱笔：起笔慢、行笔快、收笔轻 |

**编排规则。**

- 同组元素逐行错峰 70ms（`line`），自上而下、自右而左（竖排时）。
- 入场位移不超过 `space-3`（网页 12px），只向上或向左；竖排的题签、标题可以沿书写方向向下（`fall`），像墨顺着行落下；位移和透明度分开计时：位移用 `glide` + `paper`，透明度用 `ink` + `ink`。
- 一屏里先出主角，再出说明，最后才是印章。
- 减少动态效果时：所有位移取消，只保留透明度洇出；朱笔直接显示为画好的状态。

### 高光时刻

**朱笔下划线。** 全屏最要紧的半句话下面，一道朱色笔画从左到右划过（`lift` 1200ms，`brush` 缓动），笔画两端收细，像校书人随手的一笔。一屏、一页最多一次，只给最关键的一句；它出现之前，画面上的其他东西都已经安静下来。社交配图里它是画好的静态笔画，仍然只有一道。

**载体映射。**

| 载体 | 做法 |
| --- | --- |
| 展示型网页 | 首屏：标题洇出后朱笔划过。往下滚动的各段逐段洇出；满版图版揭去衬纸（`lift`）。按钮悬停时下方出现一道细朱线（`dot`） |
| HTML 幻灯片 | 翻页如纸张从右侧滑入（`glide` + `paper`，`sheet` 投影），上一页后退 `space-8`（约页宽的 7%）并蒙一层 `ink-shade`，写在 `slides.transition.json`。页内：先出主角（升起或从左滑入，`glide` + `paper`，位移 `space-3`），再洇出说明（`ink` + `ink`），同组逐行错峰 `line`，印章最后按下落定（`stamp`，`turn` + `press`，放大倍数 `motion.stampScale` = 1.12）；图版上的衬纸进页后揭去（`peel-*`，`lift` + `paper`）；关键页的朱笔下划线等同屏其他元素洇出之后（`data-ds-wait` 取 `glide`）才从左到右划出（`draw-x`，`lift` + `brush`） |
| 社交配图 | 没有动效。用竖排的向下方向、朱笔的从左到右来暗示阅读的顺序 |

## 结构骨架

使用全库三个载体的骨架，暂不增加本体系专属的叙事单元。

- 社交配图：标题型、金句型、清单型、数据型，各两种排法（见「版面」）。
- HTML 幻灯片：封面、目录、章节、观点、数据、对比、流程或时间线、引用、图片、结尾，各两种排法（见「版面」）。
- 展示型网页：首屏、问题、方案、特性、证据、流程、行动号召、页脚，各两种排法（见「版面」）。
