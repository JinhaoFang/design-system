# 生图配方

纸本编辑里代码画不好的图（人物、真实场景的光影）改用生图模型。这里只放提示词和做法，不放接口地址和密钥（方案 v0.3 第 5.4 节）。

| 图像标识 | 提示词 | 成品 |
| --- | --- | --- |
| `primary-mirror` | `primary-mirror.txt` | `images/primary-mirror.webp` |
| `eyepiece-night` | `eyepiece-night.txt` | `images/eyepiece-night.webp` |

- 模型与参数：`gpt-image-2`，`quality: high`，请求尺寸 `1536x864`（服务实际返回约 1.15:1 到 1.1:1 的画幅，照用）。
- 画风要求都写在提示词里：铜版蚀刻、只有墨线排线和点描、暖褐黑墨（`#1f1a14`）印在暖白哑光纸（`#f1ebdf`）上、全图只有一处朱色（`#b23a26`）、四周留纸并渐隐、不出现文字。
- 挑图：每次生成后逐张看，选人物姿态自然、仪器与设定一致的一张（`eyepiece-night` 第一次出成了黄铜折射镜，与 1.6 米反射镜的设定不符，重写提示词后重生成）。
- 后处理：PNG 转 WebP（质量 0.86），不做调色。要叠加标注、朱笔或动效时，在排法或定制片段里用代码叠在图上，不改图片本身。
