# 色纸剪贴

一张浅暖灰的纸上，贴着几十片用水粉色纸剪出来的叶子。它们先聚成一束，读着读着散开，最后又聚成一棵树。旁边是一封信，你读到哪一句，哪一句就亮起来。

## 意图

**为谁。** 给要说一番心里话的机构：周年纪念、节日致谢、写给志愿者或会员的信、讲立场的专题页。观看者不是来找按钮的，是来读的。

**传达什么。** 温暖、真诚、每个人都被看见。颜色很热闹，但页面很安静：热闹给叶子，安静给字。

**调性位置。** 静动 4 · 疏密 2 · 冷暖 4 · 轻重 2 · 庄谐 3。比孔版印刷疏朗得多、更庄重，比纸本编辑更活泼、更暖。

**不适合。** 产品功能页、价格页、数据密集的报告；需要很多图片和截图的内容。只有一两句话的页面也不适合：逐句点亮需要一封真正的信。

**关键规则。**

1. **颜色只给叶子，不给界面。**
   - 理由：八种水粉色同时出现已经很热闹，再给标题、按钮、底色上色就吵了。文字只用暖近黑，界面只有纸和墨。
   - 适用边界：所有网页。唯一的例外是剪出来的大数字，它本身就是一片「剪纸」。
2. **一页只有一组叶子，从头贯穿到尾。**
   - 理由：叶子是同一个主视觉在不同段落里的不同形态（聚、散、落、再聚），这样散开和聚拢才有叙事；每段换一套装饰，就只是装饰。
   - 适用边界：一件作品。排法单独使用时，叶子只作小量点缀，不超过五片。
3. **信每句独占一行，未点亮时也读得清。**
   - 理由：一句一行，逐句点亮的节奏才成立；未点亮的句子要满足 AA，不能为了效果牺牲读者（原范例未读的句子灰到几乎看不见）。
   - 适用边界：信件段落。句子长于一行时允许折行，不拆句。

## 材质锚点

**刷了水粉的色纸，用剪刀剪成叶子，边缘是手剪的圆钝曲线，贴在浅暖灰的纸上；纸片只在被拿起时才有一点薄影。**

| 方面 | 推出什么 |
| --- | --- |
| 光 | 平铺的纸面没有光影；叶子飘起时才有一层很薄的暖影（`shadow.lift`，光从左上 135°），落定后影子消失 |
| 表面 | 水粉哑光，色块内部是平的；纸面颗粒极淡（上限 0.04） |
| 边缘 | 手剪：曲线圆钝、略不规则，没有描边；叶脉是剪开的细缝，露出底下的纸色 |
| 色温 | 纸是浅暖灰，墨是暖近黑；八种水粉色饱和而不刺眼 |
| 图像处理 | 叶子和小图形用代码画（每片都是独立的形状）；有人物或场景的插图用生图，同样是水粉剪纸的画风 |
| 手感 | 纸片飘落：慢慢落下，带一点摇摆后停住，不回弹；读信时像有人用手指一行行划过去 |

#### 用色

- **规则**：八种水粉色只用在叶子、剪纸图形和剪出的大数字上；文字、按钮、底色只用纸和墨。剪出的大数字只用对比度够的朱、钴、靛、松。
- **理由**：热闹和安静分开放，颜色越多越要管住用处。
- **适用边界**：全部网页。生图的插图同样限定在这八种颜色加纸色。

### 字体

#### 中文搭配

- **规则**：全部文字用思源黑体 400，标题也不加粗；西文和数字用 Inter，剪出的大数字用 Inter 700。信件正文行距 2.2，比普通正文更松。
- **理由**：像一封用工整字写的信：没有衬线的仪式感，也没有粗体的喊叫，字号和行距负责层级。
- **适用边界**：标题不超过 `head` 档；只有剪出的数字和首屏标题可以到 `title`（手机上首屏标题回到 `head`）。不用粗体强调句子，强调靠单独成行。

| 字阶 | 网页像素 | 用在 |
| --- | --- | --- |
| `caption` / `note` | 12.75 / 14.875 | 叶签、说明 |
| `body` / `lead` | 17 / 20.4 | 正文、信件 |
| `sub` / `head` | 25.5 / 37.4 | 段落标题、首屏一行字 |
| `title` / `display` | 57.8 / 88.4 | 剪出的数字 |
| `colossal` | 153 | 只给一个剪出的大数字 |

#### 混排

- **规则**：中西文、数字之间留间距；信件每句一行，句末标点跟着句子，不单独成行。
- **理由**：一句一行的节奏不能被零碎的标点打断。
- **适用边界**：共享槽位由构建器补混排间距；定制片段手写空格。

### 版面

网页基准为正文 17px、间距单位 8px、时长基准 40ms。首屏跳跃率 2–16、版面率 0.08–0.50、图版率 0–0.60。

- **规则**：大量留白。信件栏宽不超过 26em，一侧放信，另一侧留给叶子；段与段之间至少 `space-10`。整页节奏是「一束叶子 → 读信 → 叶子散开成墙 → 读信 → 剪出的数字 → 叶子聚成树 → 落款」。
- **理由**：读信要慢，留白就是放慢的节拍；叶子在另一侧移动，读者的余光能看到它们，又不打扰阅读。
- **适用边界**：手机上信在上、叶子在下，叶子缩小，不压文字。相邻单元不用同一种排法。

### 形态

- **规则**：叶子是手剪的圆钝曲线，叶脉是剪开的细缝（露出纸色）。按钮只有一种：墨色胶囊，悬停时像纸片被拿起一点（上移 `space-1`，薄影淡入）。叶签是 `paper-deep` 的小纸条，一端剪成燕尾。不用卡片、描边、图标库。
- **理由**：所有形状都要像是用剪刀做出来的；方正的界面控件放进来就破了。
- **适用边界**：内容作品。体系总览页的控件由工具生成，不作为范本。

### 图像与画风

- **规则**：叶子、剪出的数字、负形色纸由 `images/src/` 的脚本用代码画，每片叶子是一个独立元素，便于散开和聚拢。有人物、建筑或场景的插图用生图，画风是水粉刷色的手剪纸拼贴，只用八种颜色和纸色。
- **理由**：叶子要单独运动，只能是代码里的独立形状；剪纸的平涂图形代码画得准，人物和场景代码画得僵，交给生图。
- **适用边界**：生图配方见 `images/src/prompts/README.md`，不放接口地址和密钥。

#### 无图方案

- **规则**：没有插图时，只用代码画的叶子和负形色纸：一小束叶子、一张剪出叶形窗的色纸，加上逐句点亮的文字。
- **理由**：识别度来自叶子的形态和颜色，不靠照片。
- **适用边界**：叶子不铺满背景，不压文字。

### 识别符号

- 散开又聚拢的剪纸叶子：同一组叶子在页面里聚成一束、散开、落下，最后聚成一棵树
- 正负形：剪下来的叶子，和色纸上留下的叶形窗并排出现
- 逐句点亮的信：未读的句子盖着一层薄纸，读到哪句，那层纸就从左往右揭开

## 动效语言

**性格：纸片飘落，慢慢停住。** 不回弹，不循环，不自动播放持续的动画。

| 时长 | 数值 | 用在 |
| --- | --- | --- |
| `snap` | 120ms | 焦点 |
| `lift` | 240ms | 按钮被拿起 |
| `settle` | 560ms | 透明度、文字入场、点亮前的停顿 |
| `drift` | 880ms | 叶子飘落 |
| `read` | 1200ms | 一句信被揭开 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `drift` | cubic-bezier(.3,.05,.2,1) | 叶子飘落，最后很慢地停住 |
| `settle` | cubic-bezier(.25,.1,.25,1) | 透明度、文字 |
| `read` | cubic-bezier(.45,0,.55,1) | 揭开一句，匀速的手指 |
| `lift` | cubic-bezier(.2,0,0,1) | 按钮拿起 |

### 编排规则

- **规则**：叶子用 `fall` / `left` / `right` + `drift` + `drift`，位移 `space-7` 到 `space-9`，同组错峰 `leaf`（80ms），像一片接一片落下；透明度 `settle`。信件句子用 `peel-right` 揭去薄纸，时长 `read`，进入视口后先等 `settle`；同时进入视口的几句错峰 `sentence`（640ms）。
- **理由**：叶子的位移比别的体系大，因为飘落本来就要走一段路；揭开慢一点，像有人陪着读。
- **适用边界**：只动 transform 和 opacity。减少动态效果时叶子只淡入，句子的薄纸直接淡出。

### 高光时刻

- **规则**：全页一处：叶子聚成一棵树。几十片叶子按从下到上的顺序飘落到树冠的位置，最后一片落定后，邀请的文字和按钮才出现。
- **理由**：前面所有的散开都在等这一次聚拢，它就是作品概念本身。
- **适用边界**：只在一件作品的高潮段落出现一次；首屏的叶子束随普通编排出现，不算高光。

## 范例

- 体系样张：`works/web.json`，「栖桐植物园百年 · 致每一位种过树的人」。题材由用户在 2026-11-11 选定，内容与作品概念由设计负责人定。作品概念是「一百年，每一片叶子都不一样」：志愿者像园里的叶子，形态各异，最后聚成一棵树。
- 参考范例：已批准的 `pola-mothers-day` 提供散开再聚拢的叙事、逐句点亮的信和配色关系；本体系改用手剪水粉色纸，修正了原作未读句子对比度不足、正文偏小、只能用滚轮推进的问题（本页是普通滚动页面，键盘和读屏都能读完）。
- 图像：叶子、负形色纸、排法和定制片段由 `images/src/build.mjs` 生成；测试内容的四张插图是生图，配方见 `images/src/prompts/README.md`。
- 验收记录见 `acceptance.md`。
