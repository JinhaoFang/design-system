# 孔版印刷

一台双滚筒的孔版印刷机：荧光粉一只墨，蓝一只墨，纸过两遍，两种墨叠在一起成了紫，第二遍总差那么一点没对准。

## 意图

**为谁。** 给想要热闹、有人情味的活动和小团体：观测夜、市集、展览、社团、独立出版、工作坊。观看者是被吸引过来的，先被颜色抓住，再停下来看清楚时间、地点和怎么参加。

**传达什么。** 好玩、亲手做的、有现场感，但信息一眼就能查清。热闹全部来自印刷本身——两只墨的叠色、网点、错版和颗粒——不来自堆砌装饰。

**调性位置。** 静 4 · 疏 4 · 暖 4 · 轻 2 · 庄 4。画面满、颜色跳、像在动，但每一块颜色都说得出它是哪一版墨、为什么在那儿。

**不适合。** 需要庄重、权威、精密感的场合（年报、讣告、金融、医疗说明）。硬要用，孔版印刷会显得轻佻；换纸本编辑或精密工业。

**关键规则。**

1. **一件作品只有两只墨和纸色：荧光粉、蓝，以及两者叠印出的紫。**
   - 理由：孔版机一次装一个滚筒，双色印刷就是两只墨；「只有两只墨」是这套体系的纪律，热闹必须在这个约束里做出来，才不会变成五颜六色的花哨。
   - 适用边界：任何载体、任何图像都成立。不加第三种墨，不用渐变色，不用灰；浅色调只能用网点得到。
2. **热闹有预算（见「版面」的预算表）。** 错版一屏一处，网点和斜纹各有用量上限，信息区保持安静。
   - 理由：热闹是一种执行品质，不是没有节制。每一处跳动都必须有位置，否则就是「花里胡哨」（ADR-0001）。
   - 适用边界：任何载体都成立。
3. **要查的信息一律蓝墨实印、不错版、横排，数字用等宽等高数字。** 日期、场次、价格、名额、地址、步骤都属于这一类。
   - 理由：热闹的版面里，信息区是读者唯一能放心落脚的地方；错版和荧光色会让核对出错。
   - 适用边界：任何载体都成立，没有例外。

## 材质锚点

**Riso 孔版印刷：荧光粉与蓝两只墨的套色、错版与油墨颗粒。**

| 方面 | 推出什么 |
| --- | --- |
| 光 | 没有场景光。印刷品是平的：版面上不画高光，不用渐变光影。只有纸被送进印刷机的那一刻（翻页、卡片滑入）才有一道很浅的紫色投影，向右下（135°） |
| 表面 | 未涂布的米白纸，墨吃进纸里，哑光。表面有细密的油墨颗粒（强度上限 0.1），颗粒带紫色调，不用灰 |
| 边缘 | 实地边缘干脆，直角；版的边缘有一点点毛（模版的微小抖动）。唯一的圆是粉色圆章和网点本身。线是实印的粗线（2–8px），不用发丝线 |
| 色温 | 纸偏暖（OKLCH 色相约 86°），两只墨是荧光粉（色相约 350°）和中蓝（约 264°），叠印的紫（约 289°）是第三种「颜色」。不用纯黑纯白 |
| 图像处理 | 分色版：每张图拆成蓝版和粉版两层网点或实地，正片叠底；粉版按体系常量错开。亮部靠留纸（反白），暗部靠两版叠成紫 |
| 手感 | 纸张进机：快速平移进来，轻轻一抖停住。套版落定：粉版先偏得多一点，再「咔嗒」落到规定的错位。油墨压印：圆章按下去，略大一点再落定 |

## 视觉语言

### 色彩

两只墨加纸，就是全部颜色。

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| `paper` | `#f4efe4` | 纸面，所有载体的底色；反白文字的颜色 |
| `paper-deep` | `#e9e1cf` | 另一种纸（票券、卡片、页脚），像换了一张有色纸 |
| `blue` | `#3255a4` | 蓝墨：全部正文、信息、标题、实地、线 |
| `pink` | `#ff48b0` | 荧光粉墨：大面积色块、网点、错版层、圆章 |
| `purple` | `#321871` | 蓝压粉的叠印色：粉色实地上的字、两版重叠处 |
| `blue-shade` | `#3255a4`，透明度 0.16 | 翻页时被压在下面的那张纸的暗影 |

- **文字只有三种颜色：纸上用蓝，粉上用紫，蓝实地里反白成纸色。**
  - 理由：荧光粉在米白纸上的对比度只有 2.6，不能单独承担文字；蓝在纸上 6.2，紫在粉上 4.5，纸在蓝上 6.2，都过 AA。
  - 适用边界：任何载体都成立。粉色永远不单独印字；错版层的粉字是装饰（伪元素，不承载信息）。
- **叠印出来的紫不是第三只墨。** 它只出现在蓝与粉相叠的地方（`mix-blend-mode: multiply`），或作为粉色实地上的字色（物理上就是蓝墨印在粉上）。

### 字体

#### 中文搭配

- **标题用庆科黄油体，其余用思源黑体。** 庆科黄油体粗、方、圆角，像刻在模版上的字，只给 `title` 档以上的大标题（横排多字长标题看可读性，超过十个字改用思源黑体粗）；正文思源黑体 400，小标题和信息用 700。
  - 理由：孔版海报的标题是手刻模版的味道，正文要在热闹的版面里稳稳地读得下去；一种「刻」的字、一种「印」的字，分工清楚。
  - 适用边界：任何载体都成立。庆科黄油体不用于 `head` 档以下，也不用于正文和数字。
- **数字和标签统一用 Space Grotesk。** 日期、价格、序号、数据都用它的等宽等高数字（`tnum` + `lnum`），粗体用于大数字。
  - 理由：几何无衬线的数字像印刷机上的计数器，和庆科黄油体的方圆气质一致；等宽数字让信息列对齐。
  - 适用边界：任何载体都成立。

#### 中西文混排

- 正文字体栈只有思源黑体（`font.body`），拉丁字母和数字随思源黑体；需要强调的数字、标签、序号单独用 `font.num`（Space Grotesk 500）或 `font.num-bold`（700）。
- 中西文之间留间距（构建时自动补），中文标点挤压，避头尾按工艺规范。

### 版面

**构图比率。** 跳跃率高、图版率中高：大字很大，色块和图像把画面填满，图像是两色印的主角之一。版面率按文字所占的面积计，色块和网点不算在内，所以数值不高。

| 载体 | 跳跃率 | 版面率 | 图版率 |
| --- | --- | --- | --- |
| 社交配图 | 2.5–14 | 0.10–0.70 | 0–0.70 |
| HTML 幻灯片 | 2.5–14 | 0.10–0.70 | 0–0.70 |
| 展示型网页（首屏） | 3–14 | 0.10–0.60 | 0–0.65 |

**热闹的预算。** 这张表就是「热闹也有预算」：每一项都是一屏（一页、一张）的上限。

| 元素 | 预算 | 说明 |
| --- | --- | --- |
| 墨 | 2 只 | 荧光粉、蓝；叠印紫不算第三只 |
| 错版 | 1 处 | 只给 `title` 档以上的大字或一枚主图；方向和距离是体系常量：粉版向右 `space-1`、向上半个 `space-1` |
| 粉色实地 | 约画面的 25% | 色块、圆章、错版层合计；网点按覆盖率折算 |
| 网点 | 1 块大面积 | 一张图或一枚网点圆盘；网点不压在正文下面 |
| 斜纹带 | 1 条 | 只作分隔或数据强调，不压字 |
| 颗粒 | 强度 0.1 | 整幅一层，紫色调 |
| 圆章 | 1 枚 | 行动号召只用它 |

**错版的规则。**

- **错版是常量，不是随手调的效果。** 粉版相对蓝版的错开方向和距离全体系统一（向右 `space-1`、向上半个 `space-1`，随载体基准缩放），图像里也用同一个比例。
  - 理由：真实的孔版机每一次的套版误差都朝同一个方向；处处不同的错位看起来像故障，而不是印刷。
  - 适用边界：任何载体都成立。错版层只给大字和主图，正文、数据、日期、价格永远不错版。

**节奏。** 一屏一个主角：错版大字、两色大图、一个巨大数字，三者选一。相邻的叙事单元不用同一种排法；一页满的之后，下一页留出更多纸。

**横竖排。** 全部横排。孔版海报偶尔有竖排的日期条，本体系不用：要查的信息一律横排。

**社交配图的排法。**

| 单元 | 排法 | 说明 |
| --- | --- | --- |
| 标题型 | `haibao` 海报 | 页眉一道蓝线，庆科黄油体 display 大标题按平衡折行、粉版错开，一枚粉网点圆盘叠在标题后，副题压底 |
| 标题型 | `kuaiyin` 块印 | 一块蓝色实地里反白印标题，同尺寸的粉实地按常量错开，露出两条粉边；副题、品牌在下方纸面 |
| 金句型 | `dazi` 大字 | 金句思源黑体粗大字压满版心，一只粉色大引号叠在左上成紫，落款前一道蓝短线 |
| 金句型 | `kuangyin` 框印 | 金句放在蓝框里，同样的粉框错开；右下一枚粉色圆章写品牌 |
| 清单型 | `biaoge` 表格 | 标题下一条粉斜纹带，条目逐行横排、两位等宽序号、蓝线分行，脚注印在粉色实地条上 |
| 清单型 | `piaogen` 票根 | 清单印成一张有色纸的票，左边打孔、右边虚线票根上是条目数 |
| 数据型 | `dashu` 大数 | Space Grotesk 粗体巨大数字、粉版错开，粉网点圆盘在背后，标签与说明压底 |
| 数据型 | `wangdian` 网点 | 一枚蓝粉两色网点圆占上部，数字压在圆边上，标签与说明在下 |

**无图方案也成立。** 社交配图的八种排法都不依赖图片。

### 形态

- 直角。唯一的圆角是 `hair`（社交配图 3px、网页 2px），只给票券这类小件；唯一的圆是粉色圆章、网点圆盘和网点本身（`disc`）。
- 线都是实印的粗线：分隔线 2px、页眉线 6px、框 8px（按载体缩放），颜色是蓝或粉，不用发丝线和灰线。
- 粉色圆章：粉色实地正圆，紫色庆科黄油体字，轻微旋转（-8°）。行动号召只用它。
- 不用卡片投影、胶囊按钮、图标库、渐变。需要符号时用网点圆、实心圆、箭头「→」和斜纹带。

### 图像与画风

- **画风：两色分色版。** 每张图拆成蓝版和粉版：天空、阴影用网点渐变，山、建筑用实地，亮处留纸反白；两版叠成紫，粉版按体系常量错开。造型扁平、有一点稚拙，像手刻模版。
- **优先画「场景的剪影」。** 圆顶、山路、主镜、目镜前的人，都用大块剪影和网点讲清楚；人物不画五官，用姿态和粉色的「红光」讲故事。
- **素材来源。** 全部用代码绘制（SVG），生成脚本放在本体系的 `images/src/`，颜色直接读数值文件，保证只有两只墨。不用照片，不用图库。
- **图像在画面里的位置。** 图像可以出血、可以和大字叠在一起（叠处成紫），但一屏只有一张大图；同一件作品里不重复使用同一张图。

#### 无图方案

没有图像时，用三样东西撑起画面：错版的大字、粉色网点圆盘（或蓝实地反白块）、粉色圆章。大字用庆科黄油体 `display` 档以上，数据型用 Space Grotesk 粗体的巨大数字代替图像。

### 识别符号

- 错版大字：庆科黄油体大标题，粉版按体系常量错开，叠处成紫
- 两色网点图：蓝版、粉版两层网点叠印的图像或圆盘
- 粉色圆章：粉色实地正圆里印紫字，行动号召只用它

## 动效语言

**性格：印刷机。** 纸张被送进来，快、准、停住时轻轻一抖；粉版随后「咔嗒」落到它的错位上；最后圆章按下。动效是「印出来」而不是「飘出来」：东西从送纸方向（右、下）进来，不旋转、不缩放（圆章的一次按下除外）。

| 时长 | 数值（基准 40ms） | 用在 | 目的 |
| --- | --- | --- | --- |
| `snap` | 120ms | 透明度、悬停反馈 | 反馈 |
| `press` | 200ms | 圆章按下落定 | 叙事 |
| `feed` | 240ms | 纸张进机、元素入场、翻页 | 导向 |
| `set` | 360ms | 套版落定：粉版落到错位 | 叙事与情绪 |
| `roll` | 560ms | 整块大图、色块的滚印 | 层级 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `feed` | `cubic-bezier(.2, .9, .3, 1.12)` | 位移：纸张进机，快进快停，末尾轻微过冲一下再停住 |
| `set` | `cubic-bezier(.6, 0, .2, 1)` | 套版：先慢后快，最后锁定 |
| `press` | `cubic-bezier(.25, 1.5, .5, 1)` | 圆章按下：压过头一点再回到位 |
| `ink` | `cubic-bezier(.4, 0, .2, 1)` | 透明度：墨显现 |

**编排规则。**

- 同组元素逐行错峰 80ms（`line`），自上而下；分段之间用 160ms（`beat`）。
- 入场位移不超过 `space-3`，方向沿送纸方向：向左（从右侧进来）或向上（从下方进来）；位移和透明度分开计时：位移 `feed` + `feed`，透明度 `snap` + `ink`（数值文件里声明为入场透明度的默认值）。
- 一屏里先出主角（大字的蓝版、大图），再出信息，然后套版落定，最后才是圆章。
- 减少动态效果时：所有位移取消，只保留透明度；错版层直接显示在规定的错位上。

### 高光时刻

**套版落定。** 大标题（或大数字、主图）的蓝版先印上，信息随后出现；等画面静下来，粉版从右侧多偏出一档的位置「咔嗒」落到体系规定的错位（`set` 360ms，`set` 缓动），叠印的紫在这一刻出现。一屏、一页最多一次。社交配图里它是印好的静态错版。

**载体映射。**

| 载体 | 做法 |
| --- | --- |
| 展示型网页 | 首屏：标题蓝版进来、导语和图出现后，粉版套版落定，最后圆章按下。往下滚动的各段按送纸方向进入。按钮式的入口一律做成圆章或票根，悬停时圆章微微压下 |
| HTML 幻灯片 | 翻页如纸张送进印刷机：新页从右侧快速滑入、轻抖停住，旧页被压在下面变暗；关键页在翻页停稳后套版落定 |
| 社交配图 | 没有动效。错版的方向（向右上）暗示粉版是「后印上去的」 |

## 结构骨架

使用全库三个载体的骨架，暂不增加本体系专属的叙事单元。

- 社交配图：标题型、金句型、清单型、数据型，各两种排法（见「版面」）。
- HTML 幻灯片、展示型网页的排法在后续阶段补齐。

## 范例

- 标准样张的社交配图：作品描述在 `works/`。
- 参考范例：范例库里已批准的 `riso-risotto-studio`（四五只墨里的克制、套印混色）、`riso-colossal-riso-club`（错版和颗粒当作优点）、`riso-tokyo-art-book-fair`（实地色块加压线、信息排得一丝不苟）。本体系把它们收紧成两只墨。
- 体系验收后，标准样张作为「原创」范例提交。
