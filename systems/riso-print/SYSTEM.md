# 孔版印刷

两只墨，一张暖纸。大字先把人叫来，蓝墨的信息让人放心核对。

## 意图

为观测夜、市集、展览、独立出版和小团体活动提供热闹、亲手印制的现场感。调性为动、密、暖、轻、谐；不用于医疗、金融或庄重纪念活动。

### 双墨纪律

- **规则**：一件作品只有荧光粉、蓝两只墨与同一种纸色；紫只由两版叠印产生，或用于粉色实地上的蓝墨文字。不加黄、灰或第三只墨，不用颜色渐变，浅调由网点覆盖率表达。
- **理由**：约束墨数使热闹来自印刷关系，而不是堆颜色；紫是套印结果，不是另一滚筒。
- **适用边界**：所有网页、定制片段与图像。数值中的 `ink`、`ink-2`、`rule`、`accent` 均为蓝的语义别名，不增加墨数；`paper-deep` 与 `paper` 为同一纸色。体系总览里的色带用来解释墨版，不能照抄成多色装饰。

### 信息优先

- **规则**：正文、数据、日期、价格、地址和步骤都横排、蓝墨实印、不错版。数字及拉丁标签统一用 Space Grotesk，数字开启 `tnum` 和 `lnum`；中文标签用思源黑体。
- **理由**：活动信息必须能查清；荧光粉的小字、错位数字都会妨碍核对。
- **适用边界**：所有信息区。蓝实地里的文字可反白为纸色；粉实地上的文字为叠印紫。不要在网点图上压正文。

## 材质锚点

**Riso 孔版印刷的套色、错版与油墨颗粒。**

| 方面 | 从材质推出的做法 |
| --- | --- |
| 光 | 平面印品没有场景高光、渐变照明或塑料反射。仅送纸动作可带数值里的右下投影，光源方向 135°；静态页面不用投影 |
| 表面 | 暖米白未涂布纸，墨渗入纸面；细颗粒只在墨版里出现，整幅强度不超过 0.1，不叠写实纸纹 |
| 边缘 | 实地边缘干脆，模版有轻微毛边；分隔线 2px、页眉线 6px、框 8px，来自起点；只有网点、月盘和圆章是圆 |
| 色温 | 纸 `#f4efe4` 偏暖，荧光粉 `#ff48b0` 与蓝 `#3255a4` 叠成紫，不用纯黑纯白 |
| 手感 | 纸快速进机，轻抖停住；粉版等画面静下来再落定；圆章压下后回到印面 |

### 材质用量

- **规则**：只用分色网点、实地和轻微模版毛边；颗粒只留一层，强度不超过 `grain.max`（0.1）。页面纸面保持干净，不再铺第二层全屏噪声。
- **理由**：真实墨粒已经在图像边缘和网点密度里，重复覆纹会让正文脏、让网点糊。
- **适用边界**：图像与背景均适用。SVG 的毛边是模版边缘，不等于照片纹理；不要追加胶片颗粒或材质贴图。

## 视觉语言

### 色彩

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| `paper` / `paper-deep` | `#f4efe4` | 唯一纸面与反白 |
| `blue` / `ink` / `ink-2` / `rule` / `accent` | `#3255a4` | 正文、数字、标签、界线和系统页控件 |
| `pink` | `#ff48b0` | 大字装饰墨版、网点、斜纹带、圆章 |
| `purple` | `#321871` | 粉底上的蓝墨字，代表叠印；实际正片叠底随底色合成 |
| `blue-shade` | 蓝，透明度 0.16 | 预留送纸暗影；样张未使用 |

### 文字颜色

- **规则**：纸上蓝字、蓝上纸字、粉上紫字。粉底上的标题和圆章文字用紫表示蓝墨叠印。荧光粉不单独承担可读文字；装饰性粉版大字用 `aria-hidden`，对应蓝版文字只读一次。
- **理由**：粉在纸上的对比度不足，不能承担信息；蓝在纸上和纸在蓝上满足正文 AA，紫在粉上满足正文 AA。
- **适用边界**：全页。SVG 叠印和滤镜目前需要人工核对，不能以压图警告为理由把信息印成低对比度。

### 字体

#### 中文搭配

- **规则**：庆科黄油体 400 只用于 `title`（68px）及以上的短大标题；多字长标题使用思源黑体 700。正文思源黑体 400，分段标题 700。数字与拉丁标签统一 Space Grotesk 500 / 700；不用快乐体。只用字体清单条目。
- **理由**：刻版味道留给大字，长句和信息交给清楚的无衬线。数字用一款几何无衬线使全页一致。
- **适用边界**：短标题优先在词组边界折行；十字以上或读不顺时切换思源黑体粗体。不能为了塞进容器随意缩字号。

| 字阶 | 网页像素 | 用在 |
| --- | --- | --- |
| `caption` / `note` | 12.75 / 14.875 | 辅助说明、眉题 |
| `body` / `lead` | 17 / 21.25 | 正文、导语、数据标签 |
| `sub` / `head` | 27.625 / 42.5 | 分段标题、引文 |
| `title` / `display` | 68 / 110.5 | 短海报标题；手机用 title，桌面用 display |
| `poster` / `colossal` | 170 / 238 | 特别短的展示字；本网页未使用 |

### 混排

- **规则**：中文与西文、数字之间留间距，遵守工艺规范的避头尾、孤字检查；全页横排，长段落 `text-wrap: pretty`，多行标题平衡折行。
- **理由**：双墨的热闹不能牺牲中文阅读，日期必须沿同一阅读方向核对。
- **适用边界**：共享槽位由构建器补混排间距；定制片段由生成脚本明确写空格。无文字 SVG 图案不承担正文。

### 版面

网页基准为正文 17px、间距单位 8px、时长基准 40ms。首屏跳跃率 3–14、版面率 0.10–0.60、图版率 0–0.65；数据表不靠放大数字伪造跳跃率。

| 项目 | 一屏上限 | 使用方式 |
| --- | --- | --- |
| 墨数 | 2 只 | 蓝与荧光粉 |
| 错版 | 1 处 | 只给 title 档及以上的大字或一枚主图；一屏不同时错版图与字 |
| 错位 | 固定右 4px、上 2px | 由网页 `space-1` 与半档推出；不逐处调方向和距离 |
| 粉实地 | 约 25% 画面 | 网点按覆盖率折算，圆章和粉字合计 |
| 网点 | 1 块主图 | 月历是一个数据组，最多 8 枚小月盘，不再加网点背景 |
| 颗粒 | 一层，强度 0.1 | 已有墨版边缘与网点，不追加全屏噪声 |
| 斜纹带 | 1 条 | 数据分段，不压字 |
| 圆章 | 1 枚 | 行动号召；同屏不得重复 |

### 错版

- **规则**：粉版向右 `space-1`、向上半个 `space-1`。这只是统一的静态套色误差；高光入场额外位移用 `space-3`，结束回到该误差。只给大标题和主图，一屏最多一处；装饰重复内容标 `aria-hidden`。
- **理由**：一台印刷机的误差朝同一个方向，随手调整会像显示故障；控制次数使装饰不抢信息。
- **适用边界**：按载体基准缩放；本期只有网页。标准图像的蓝粉版对齐，不再自带错位，避免首屏与大字重复消耗预算。首屏两行字作为同一标题、同一处错版、同一批次落定。

### 整页节奏

- **规则**：首屏海报之后进入紧凑的蓝墨信息网格；问题、参数和年表各以一块粉底叠印标题为印刷主角，数据与正文仍为蓝墨实印；读完仪器、参数，再出现唯一的满版观测现场；其后数据、时间线与八夜月历收束，预约圆章与牌记结尾。普通段上下间距用 space-7，手机用 space-6，比原先分别下调两档；首屏随内容展开，不用整屏最小高度制造问题标题前的空白。相邻单元不用同一种排法，满版高潮全页一次。
- **理由**：热闹需要停顿，也需要密集的印刷节奏；粉色标题实地与粗蓝序号承接海报，录表负责核对，满版图负责把参数还原成体验。
- **适用边界**：这是一件作品的节奏，不要求每个网页照搬单元次序；新增内容先保证一屏一主角，不允许连续多段都用出血图。

### 形态

- **规则**：直角实地与 2–8px 粗线；`hair` 圆角仅给小票件，`disc` 仅给圆章与月盘。行动号召统一用粉色圆章：圆形粉墨实印，文字用粉底上的叠印紫；首屏指向月历，预约段指向预约地址。票根只作为信息排法，不能把虚线矩形当主要行动号召。不用长条应用按钮，不用卡片投影、胶囊和图标库。
- **理由**：孔版的模版与票券属于印品语汇，应用控件会把现场海报变成通用界面。
- **适用边界**：内容作品。体系总览页由工具生成，它的重放、偏好切换控件属于工具；保持蓝墨可读，不把它们当作品行动号召的范本。

### 图像与画风

- **规则**：全部图像按共享简报做成蓝粉两版的扁平剪影、网点和实地；天空靠网点密度、亮处留纸。合作方标识单蓝墨。相同图像在一件作品里只出现一次；一屏一张主图，不在正文后铺网点。
- **理由**：两只墨可以表现明暗、红光与现场；独立画面让首屏、仪器说明和高潮各有叙事任务。
- **适用边界**：`images/src/` 的脚本生成圆顶、盘山路、观测夜、洁净室主镜和五个合作方标识。非照片、不用素材图库。年表只保留有顺序含义的蓝墨序号，删去无含义的网点球。观测夜的镜筒、遮光罩、调焦座、转向目镜、叉臂与三脚架按结构绘制，镜筒用蓝墨网点密度区分亮暗；人物保留粉色网点剪影。盘山路图版占满内容栏。月相按纸本编辑已有日期模型估算，亮面粉色疏网点、暗面蓝色密网点，最多八夜；不是随机装饰月牙。

#### 无图方案

- **规则**：移除图像时由短大字、蓝墨实地与参数录表撑起版面；最多一处粉版大字和一枚行动圆章，不补无意义插画。
- **理由**：识别度首先来自双墨与字阶，不依赖一张图库照片。
- **适用边界**：无图活动页以海报式大字替代图像槽位，工艺检查仍照常；不能添加第三种识别符号或装饰图标。

### 识别符号

- 错版大字：蓝版可读、粉版装饰重复，统一向右上偏移
- 两色网点图：蓝粉网点密度和叠印关系表现明暗
- 粉色圆章：紫字压在粉实地上，行动号召的印记

## 动效语言

**性格：纸进机、套版落定、圆章压印。** 不持续摆动，不自动循环。

| 时长 | 数值 | 用在 |
| --- | --- | --- |
| `snap` | 120ms | 透明度、反馈 |
| `press` | 200ms | 圆章压印 |
| `feed` | 240ms | 纸张进机、信息入场 |
| `set` | 360ms | 粉版落定 |
| `roll` | 560ms | 大图滚印、等待画面静下来 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `feed` | cubic-bezier(.2,.9,.3,1.12) | 快速送纸，轻微抖动停住 |
| `set` | cubic-bezier(.6,0,.2,1) | 套版最后锁定 |
| `press` | cubic-bezier(.25,1.5,.5,1) | 圆章压下回位 |
| `ink` | cubic-bezier(.4,0,.2,1) | 墨显现 |

### 编排规则

- **规则**：位移用 `feed` + `feed`，距离不超过 `space-3`；同组逐行错峰 `line`（80ms），段间 `beat`（160ms）。位移和透明度分开计时，透明度默认 `snap` + `ink`，声明在数值文件 `entrance.opacity`。所有逐行清单显式递增名次。
- **理由**：纸要快进、轻抖、停住；墨显现不必跟随位移拖到结束。逐行顺序让读者循序核对。
- **适用边界**：网页首屏与滚动入场。图像可用 `roll`；只动画 transform 与 opacity，不改宽高、颜色或布局。减少动态效果时取消位移、错峰与额外等待，只淡入。

### 圆章反馈

- **规则**：悬停和键盘聚焦用 press 时长与 press 缓动把圆章压到 stampScale 的倒数；按下再沿送纸方向下移 space-1，松开回到印面。只过渡 transform，不改色彩、宽高或布局。
- **理由**：粉墨圆章的反馈要像压印，让观看者确认手下有一枚印章。
- **适用边界**：所有主要行动圆章。减少动态效果时取消反馈位移与缩放，保留聚焦轮廓；首屏入场高光仍只给粉版标题，圆章随普通信息送入，预约段圆章才以 stamp 入场。

### 高光时刻

- **规则**：一屏一次。首屏蓝标题与导语先出现，圆顶图完成后粉版才用 `data-ds-wait` 落定。两行同一标题同名次；静态截图保留规定错位。圆章用 `press` + `press` 与 `stampScale` 1.18，等同屏普通信息全部结束才压下。
- **理由**：高光是一回印制动作，不是所有装饰争先播放。先让观看者读清，再给套色落定的乐趣。
- **适用边界**：首屏标题与眉题名次 0、导语和图像名次 1、圆章名次 2、两行粉版名次 3。粉版等待 `roll`（560ms），起点为 800ms；蓝版和导语最晚 320ms 完成、图像最晚 640ms 完成、圆章最晚 400ms 完成。两行粉版同组同名次，作为一次套版动作。后续普通图只滚印，不再套版高光。减少动态效果时粉版直接保留静态错位。

## 结构骨架

本期只做网页。沿用全库网页骨架，不增加体系专属单元：首屏、问题、方案、特性、证据、流程、行动号召、页脚，每个单元至少两种排法。社交配图、幻灯片、PDF 与衍生脚本不交付。

### 结构使用

- **规则**：复用排法引用骨架槽位与共享内容；只在作品概念需要时插入定制片段，片段注明服务于哪一段叙事。
- **理由**：体系提供可替换的编排语汇，样张必须是一件作品，不是总览的平铺。
- **适用边界**：首屏海报、满版目镜场景、八夜月历是生成片段；其余样张由普通排法组成。定制片段同样经过检查器。

## 范例
