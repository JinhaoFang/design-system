# 油画网点

一幅古典油画里的人，手里拿着一部用旧报纸网点印出来的手机。人的部分有笔触和温度，机器的部分是黑白的点。

## 意图

**为谁。** 给做技术、但想让人感到「这里有人」的机构：AI 与数据实验室、研究团队、开放数据和公益技术项目、面向创作者的工具。观看者多半见过太多冷蓝渐变和发光网格，想知道这家机构在意什么。

**传达什么。** 技术是为人服务的，人的经验和手艺在前，机器在后。页面要安静、可信、有一点机智：油画里出现一部网点手机，本身就是个会心一笑的玩笑。

**调性位置。** 静动 3 · 疏密 2 · 冷暖 3 · 轻重 3 · 庄谐 3。比纸本编辑多一分重量（油彩的厚度、深青实地）和一分机智（古今错置），比孔版印刷安静得多。

**不适合。** 促销、倒计时、密集数据看板；也不适合本身就是古典题材的文化机构（那里油画不再是「错置」，没有张力，用纸本编辑）。需要多屏连续的产品界面截图时，网点只能用于实物设备，不能把界面截图做成网点。

**关键规则。**

1. **一幅画里只有现代设备是网点。**
   - 理由：油彩代表人的审美和手艺，网点代表机器和数据，两种材质的对照就是这套体系要讲的话。网点扩散到人身上或背景里，对照就没了。
   - 适用边界：所有插图。网点边缘可以散成少量深青方块，但方块不超过设备自身面积的一半。没有现代设备的画（例如群像）整幅油彩，最多一件网点物件。
2. **图负责热闹，字和底负责安静。**
   - 理由：油画本身信息量大，再加装饰色、渐变或图标，画面就吵了。
   - 适用边界：任何一屏。色块只用从画里取出的灰绿、灰青、深青，一屏最多一块深青实地。
3. **超大字号一页最多两次。**
   - 理由：超大细衬线字是改变节奏的手段，用多了就成了常态，失去换气的作用。
   - 适用边界：网页。超大字（`colossal`、`giant`）只放三五个字以内的短语或数字，不放句子。

## 材质锚点

**布面油画里的人和衣褶，手里的现代设备印成黑白网点；底下是带细颗粒的暖米白纸。**

| 方面 | 推出什么 |
| --- | --- |
| 光 | 画室的北窗光，从左上来（135°），软而有方向。光只存在于画里：页面上的卡片、按钮不加投影，层次靠色块深浅 |
| 表面 | 画布有笔触，纸面有极细颗粒（强度上限 0.06）；网点是印刷的硬点，没有笔触。界面元素哑光、平涂 |
| 边缘 | 画作四周渐隐进纸，不加画框和描边；卡片圆角两档（8px、24px），按钮是胶囊形；网点边缘散成小方块 |
| 色温 | 纸偏暖米白，墨是暖近黑；色块取自画里的灰绿和深青，偏冷，用来压住油彩的暖 |
| 图像处理 | 生图后把纸色校正到体系纸色，使画的渐隐边缘和页面无缝；不调色、不加滤镜 |
| 手感 | 颜料洇开：按钮的底色从中心晕开铺满；画像从四周缓缓飘进来再停住，不回弹 |

## 视觉语言

### 色彩

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| `paper` | `#f7f3ea` | 页面纸面，画作渐隐的去处 |
| `paper-deep` | `#efe9dc` | 次一级纸面、页脚 |
| `ink` | `#2c2620` | 正文、标题、实心按钮底 |
| `ink-2` | `#5c554c` | 次要文字、说明（纸上 6.6:1） |
| `rule` | `#d8d0c1` | 发丝线、描边按钮的边，不承担文字 |
| `sage` | `#d0e1d9` | 浅色块、卡片 |
| `celadon` | `#a7c0b9` | 按钮悬停时晕开的底色 |
| `teal` / `accent` | `#2e6b69` | 深青实地，一屏最多一块；实地上的字用纸色（5.5:1） |
| `teal-deep` | `#25595a` | 深青实地上的卡片描边与分隔 |
| `olive` | `#8e8a5a` | 只用于装饰小块和网点散开的点缀，不承担文字（纸上 3.2:1） |

#### 用色

- **规则**：页面只有纸、墨和三种画中色（灰绿、灰青、深青）；橄榄只作点缀。不另造品牌强调色，不用渐变。
- **理由**：颜色从画里来，页面和插图才是同一幅画的延伸；多一种外来的强调色，就像在油画旁边贴了一张便利贴。
- **适用边界**：全部网页。图像本身的颜色不受这条限制，但生图提示词要求画面色调落在土黄、橄榄、灰绿、深青之间。

### 字体

#### 中文搭配

- **规则**：标题用思源宋体细体（300），西文和数字标题用 Source Serif 4 细体，字距收紧到字号的 -3%；正文、按钮、标签用思源黑体 400 配 Inter；数据用 Inter 500 等宽数字。
- **理由**：细衬线标题是「画廊墙上的标签」，有人文气；无衬线正文是「实验室的说明」，清楚。两种字体分工明确，一眼能分出哪里在讲故事、哪里在讲事实。
- **适用边界**：衬线只用于 `sub` 档以上的标题和引文；正文不用衬线，衬线不用粗体。中文标题超过十四个字时改两行，不缩字号。

| 字阶 | 网页像素 | 用在 |
| --- | --- | --- |
| `caption` / `note` | 12.75 / 14.875 | 图注、标签、眉题 |
| `body` / `lead` | 17 / 21.25 | 正文、导语 |
| `sub` / `head` | 25.5 / 40.8 | 引文、分段标题 |
| `title` / `display` | 61.2 / 95.2 | 首屏标题；手机用 `head` 到 `title` |
| `colossal` / `giant` | 204 / 306 | 一页最多两次的超大短语或数字 |

#### 混排

- **规则**：中西文、数字之间留间距；衬线标题里的数字也用 Source Serif 4；正文 `text-wrap: pretty`，标题平衡折行。
- **理由**：细衬线的中西文要看起来像同一位排字工的手笔。
- **适用边界**：共享槽位由构建器补混排间距；定制片段手写空格。

### 版面

网页基准为正文 17px、间距单位 8px、时长基准 40ms。首屏跳跃率 3–22（超大字出现时可以很高）、版面率 0.10–0.60、图版率 0–0.70。

- **规则**：版心 1240px，正文栏不超过 36em；一屏一个主角，画作通常占版面一半以上，文字放在画作渐隐出来的空纸上。整页节奏是「安静的纸面段落 → 一次超大字 → 安静 → 一块深青实地 → 安静 → 第二次超大字或群像」。
- **理由**：画作需要空纸来「渐隐」，文字落在渐隐出的空白里，图和字才连成一体，而不是图片框加说明。
- **适用边界**：相邻单元不用同一种排法；深青实地全页最多两块，不相邻。手机上画作在上、文字在下，不让文字压在画面上。

### 形态

- **规则**：按钮是胶囊形，两种：墨色实心、发丝描边；卡片圆角 8px（小卡片、标签）和 24px（大面板）两档，不用第三档；不用投影、不用图标库。悬停效果全站只有一种（见动效语言「晕开」）。
- **理由**：界面元素要像画框旁边的展签和画册里的书签，平、软、少。圆角只有两档，形状才有秩序。
- **适用边界**：内容作品。体系总览页的控件由工具生成，不作为范本。

### 图像与画风

- **规则**：所有插图是生图的古典油画（17 至 19 世纪的风俗画、肖像、风景的笔法），题材是当代的人和场景；画里只有现代设备印成黑白网点，网点边缘散成几粒深青方块后消失。画作四周渐隐进纸，不加画框。生图后用 `images/src/finish.mjs` 把纸色校正到 `paper`。同一张图在一件作品里只出现一次。
- **理由**：古今错置是这套体系的识别核心；渐隐让画和页面是同一张纸。代码画不出油画的笔触，所以具象图一律生图。
- **适用边界**：提示词配方和尺寸见 `images/src/prompts/README.md`，不放接口地址和密钥。合作方标识这类图形用代码画，单色墨。人物画当代普通人，不画真实名人的样貌。

#### 无图方案

- **规则**：没有油画时，由细衬线大标题、灰绿和深青色块、一块用 CSS 圆点画的网点区域（只用墨色、一屏一块）撑起版面。
- **理由**：识别度一半来自字体分工和画中色，另一半来自「网点 = 机器」这个记号，不靠图库照片。
- **适用边界**：网点区域不压文字，不做成背景铺满；不补无意义的插画。

### 识别符号

- 油画里的网点物件：油彩的人拿着黑白网点的现代设备，网点边缘散成深青方块
- 晕开的按钮：悬停时灰青底色从中心洇满胶囊，文字向上翻出、同样的字从下面翻进来
- 超大细衬线字：一页最多两次，用来换气

## 动效语言

**性格：颜料洇开，画中人抬眼。** 慢起慢落，不回弹，不循环。

| 时长 | 数值 | 用在 |
| --- | --- | --- |
| `snap` | 120ms | 焦点、按下反馈 |
| `roll` | 320ms | 按钮文字翻滚 |
| `bloom` | 400ms | 按钮底色晕开 |
| `drift` | 720ms | 文字入场、透明度 |
| `settle` | 960ms | 画作飘入停住 |
| `linger` | 1200ms | 首屏主画缓入、高光 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `roll` | cubic-bezier(.22,1,.36,1) | 文字翻滚，先快后慢 |
| `bloom` | cubic-bezier(.5,.05,.3,1) | 底色晕开，两头慢中间快 |
| `drift` | cubic-bezier(.25,.1,.2,1) | 画作飘入 |
| `settle` | cubic-bezier(.4,0,.2,1) | 透明度、普通入场 |

### 编排规则

- **规则**：文字入场用 `rise` + `drift`，位移 `space-3`；画作用 `left` / `right` / `fall` + `settle` + `drift`，位移 `space-5` 到 `space-7`，像从画廊墙边飘进来。同组错峰 `line`（80ms），散落的小画用 `float`（240ms）。透明度统一 `drift` + `settle`（数值文件 `entrance.opacity`）。
- **理由**：字要先读到，画随后到位；小画逐张飘入，读者的视线跟着它们绕一圈。
- **适用边界**：只动 transform 和 opacity。减少动态效果时取消位移、错峰与额外等待，只淡入。

### 晕开

- **规则**：按钮悬停或键盘聚焦时，胶囊里一枚 `celadon` 圆从中心按 `bloom` 时长、`bloom` 缓动放大到盖满胶囊（被胶囊裁切）；同时文字按 `roll` 时长、`roll` 缓动向上移出，同样的一份文字从下方移入。字 320ms 先到，底色 400ms 后铺满。离开时倒放。实心按钮和描边按钮悬停后都变成灰青底、墨色字。
- **理由**：底色像颜料洇进纸里，而不是整块换色或上浮投影；字先到位，手感干脆而不生硬。
- **适用边界**：所有按钮和主要链接按钮；全站不用第二种悬停。只过渡 transform 和 opacity。减少动态效果时去掉翻滚，底色直接淡入。翻进来的那份文字 `aria-hidden`。

### 高光时刻

- **规则**：全页最多两处。首屏：标题先 `rise`，主画用 `linger` 从右侧缓缓飘入，网点设备随画一起出现，不单独动。第二处是体系样张自己的一处（例如超大字的数字段落或第二张主画）。
- **理由**：高光是一回「人抬起眼」，不是所有元素争着动。
- **适用边界**：首屏标题名次 0、导语 1、按钮 2、主画 1 并带 `linger`；其余段落只用普通编排。

## 范例

- 体系样张：`works/web.json`，「乡音库 · 让机器听懂乡音」。内容大纲由用户在 2026-11-11 确认。作品概念是「一句话的旅程」：跟着一位老人说的一句粤语，从茶楼出发，经过录音、转写、校对，最后回到他的手机上。
- 参考范例：已批准的 `contra-labs` 提供图像语法、画中取色、衬线与无衬线分工和按钮手感；本体系重做了数值，修正了原作浅色字压图、正文偏淡的问题。
- 图像：具象图是生图，配方见 `images/src/prompts/README.md`；合作方标识、排法和定制片段由 `images/src/build.mjs` 生成。
