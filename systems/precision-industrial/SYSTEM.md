# 精密工业

一块本色阳极氧化的铝板，拉丝纹一道道向同一个方向走，边缘切出一亮一暗两条倒角；上面激光刻着零件号、尺寸和参数。只有一处，面板翻过来，是一块冷色背光的仪表。

## 意图

**为谁。** 给靠精度说话的项目：仪器与装备、科研设施、硬件产品、工程进展。观看者想知道「它能做到什么、数字是多少」，愿意读表格、看图纸，不需要被氛围打动。

**传达什么。** 精确、可靠、经得起核对。页面像一份技术文件：每个数字都有单位和出处，每张图都有标注，示意图明确说明不按比例，没有一处含糊的形容词。第一眼是「专业」，细看是「准」。

**调性位置。** 静 2 · 密 4 · 冷 1 · 重 4 · 庄 1。安静而紧凑：信息密，但每一格都对齐；冷而不冷漠：安全橙的加工标记和背光仪表是人在操作机器的痕迹。

**不适合。** 需要温情、手作、慢读的文化内容，强促销和娱乐化的场合。硬要用，精密工业会显得生硬；换纸本编辑或孔版印刷。

**关键规则。**

1. **规则：每个测量读数都带单位，表格里的数字一律横排、等宽对齐。**
   - 理由：这套体系的可信来自可核对。没有单位的数字、参差的数字列，会让整份文件失去精度感。
   - 适用边界：网页内成立。标题里的测量数字也要带单位，单位用等宽字、降一档；零件号、版次、日期和列表序号不是测量读数。
2. **规则：安全橙只做加工标记、指认和唯一的强调，合计不超过画面的 3%。**
   - 理由：橙色在车间里是警示和加工标记的颜色。用多了，它就不再指向任何东西。
   - 适用边界：网页内成立。图像里的橙色光线、指示点也算进预算。橙色不排正文和小字（对比度不够），只给标记、细线、指示点和 `head` 档以上的单个字符。
3. **规则：暗页只出现一次，一件网页最多一屏，满版展开。**
   - 理由：深石墨背光的仪表页是全套的高光时刻。亮铝板是常态，暗页一出现就是重点；多了就变成科技风的仪表盘。
   - 适用边界：只用于网页满版高潮。其余所有段落回到亮铝面，暗页内不再用安全橙。

## 材质锚点

**阳极氧化铝与冷色背光。**

| 方面 | 推出什么 |
| --- | --- |
| 光 | 车间顶灯的冷白漫射光，从左上来（135°）。平铺的铝板没有投影；只有凸起的铭牌、按键投下一道短而实的影子，向右下、半径小、带墨色的冷调，不用纯黑半透明 |
| 表面 | 本色阳极氧化：哑光、冷灰带一点蓝，表面有极细的单向拉丝纹（水平方向，强度上限 0.04），铝面上的纹路用体系冷墨 `ink-2`，不另造灰色。没有高光渐变、没有金属反光的拟物 |
| 边缘 | 机加工的倒角：凸起件的上沿和左沿是一道亮发丝线（`edge-hi`），下沿和右沿是一道暗发丝线（`edge-lo`），表达切削出的棱。直角；按键也用直角 |
| 色温 | 冷。铝色、墨色、线色都在同一个冷色相（OKLCH 约 236–245°）。暖色只有安全橙一种 |
| 图像处理 | 工程图与技术插图：等宽细线、剖面线、尺寸标注、比例尺，单色墨线，橙色只指认一两处（光路、关键尺寸）。不用照片质感的金属渲染 |
| 手感 | 机械：快、准、位移短，停得干脆，不回弹。零件推入卡槽到位即止；指针扫到读数就停；标注线一笔画出 |

## 视觉语言

### 色彩

两种材料、一种信号：亮的铝板，暗的背光仪表，安全橙。

| 角色 | 色值 | 用在 |
| --- | --- | --- |
| `alu` / `background` | `#ccd5db` | 底色，本色阳极氧化铝；`background` 是同值角色，供体系总览页识别 |
| `alu-light` | `#d9e1e6` | 凸起的零件：铭牌、按键、图框里的标题栏 |
| `alu-deep` | `#bfc9cf` | 下沉的槽：表头、分区底色 |
| `edge-hi` / `edge-lo` | `#ecf1f4` / `#9ca6ad` | 倒角的亮边与暗边，只用作 1px 发丝线 |
| `ink` | `#0f1519` | 标题、正文、图框粗线 |
| `ink-2` | `#353f46` | 次要文字、图注、标签 |
| `ink-3` | `#4d575e` | 刻度、编号、页眉页脚 |
| `rule` / `rule-light` | `#96a0a7` / `#afb9bf` | 表格界线、网格、尺寸界线 |
| `signal` | `#d75a21` | 安全橙：加工标记、指认、唯一的强调 |
| `graphite` / `graphite-2` | `#0f1419` / `#161d22` | 暗页的深石墨底与面板 |
| `graphite-line` | `#2c343b` | 暗页的刻度环与界线 |
| `glow` | `#e0eaed` | 暗页标题 |
| `glow-2` | `#98a8ae` | 暗页辅助字 |
| `glow-3` | `#75838a` | 暗页刻度 |
| `backlight` | `#7bdef9` | 冷色背光：只在暗页，给指针、读数弧和唯一的读数 |

- **规则：亮页只用铝、墨、线三组颜色加安全橙；冷色背光只在暗页出现。**
  - 理由：背光是仪表通电的样子。亮页上出现青色，就像一块没通电的板上亮着灯，材料不成立。
  - 适用边界：网页内成立。暗页里不再用安全橙，背光青就是暗页唯一的强调色。
- **规则：墨色分三级，不另造灰。**
  - 理由：层级靠墨的深浅和字重拉开，第四级灰只会让表格发虚。
  - 适用边界：小字优先 `ink-2`；`ink-3` 在亮铝底上用于辅助信息，仍需通过对比度检查。

### 字体

#### 中文搭配

- **规则：黑体做标题，黑体排正文，等宽字只做标签。** 标题用思源黑体 700，正文用思源黑体 400；零件号、单位、刻度、表头、页眉这类标签用 IBM Plex Mono（中文落在思源黑体上）。
  - 理由：工程文件里，正文要好读，标签要像刻上去的。等宽字排中文正文会松散难读，只让它承担「编号与单位」的角色。
  - 适用边界：网页内成立。中文正文不用等宽字；单个字段不跨行，手机允许字段之间换行。
- **规则：字重拉开，字距收紧。** 标题 700、字距 0 到 0.02em；正文 400；标签等宽字放开到 0.06–0.1em，英文标签全大写。
  - 理由：重的标题和紧的字距给出「密、重」；标签放开字距才像激光刻字。
  - 适用边界：`display` 档以上的数字字距收到 -0.04em。

#### 中西文混排

- 数字和拉丁字母用 Inter：正文 400，读数 500，超大数字 700。正文字体栈 Inter 在前（`font.body`），数字自动落在 Inter 上。
- 表格、读数、日期、价格一律用等宽等高数字（`tnum` + `lnum`）；单位用 IBM Plex Mono，比数字小一档或两档，紧跟数字。
- 中西文之间留间距（构建时自动补），中文标点挤压，避头尾按工艺规范。

### 版面

**构图比率。** 跳跃率高、版面率高、图版率中：信息排得满，超大读数和等宽小标签的对比拉到最开（这是仪表的样子），图纸占画面的一大块。

| 载体 | 跳跃率 | 版面率 | 图版率 |
| --- | --- | --- | --- |
| 展示型网页（首屏） | 2.5–10 | 0.18–0.65 | 0–0.60 |

**图框与标题栏。** 工程图纸的一页有固定结构：外框一道墨线，右下角一块标题栏（图名、零件号、版次、比例、页码）。本体系以此为骨架：

- 图框只用于「文件性」的画面（封面、图纸区域、页脚），不给每一屏都套框。
- 标题栏是一块凸起的 `alu-light` 小板，带倒角，里面是等宽字的字段。
- 网格是 8 的倍数，所有元素落在网格上；网格线本身只在图纸区域里画出来，用 `rule-light` 的极细线。

**数字和表格。**

- **规则：要核对的信息一律进表格或读数栏：横排、等宽数字、右对齐数字列、单位紧跟。**
  - 理由：精度感来自对齐。数字列一参差，整份文件就像手抄的。
  - 适用边界：网页内成立。两项以内的数字可以并排成读数栏，不必画表。
- **规则：表格只画横线，不画竖线；表头下沉一档（`alu-deep`）或上面一道墨线。**
  - 理由：竖线把表格切成格子，读起来像电子表格；只留横线，眼睛顺着行走。
  - 适用边界：读数栏和图纸标题栏可以在字段之间用一道竖发丝线分开。

**整页节奏规则。**

- **规则：两三段密排的说明、剖面和参数后，留一屏只给表盘。暗屏前后的段落全是铝面。**
  - 理由：信息密度的变化让读数有重量；暗底和青色只出现一次，才构成高光。
  - 适用边界：标准样张在特性之后进入暗屏，证据区恢复亮面。排法总览是能力清单，不拿它当整页叙事。手机保持同样的章节顺序，表格纵向展开，不靠缩小字阶塞入屏幕。
- **规则：相邻单元不用同一种排法，首屏和高潮用作品专属片段；表格、分栏图纸和纵向工序轮换，不排等大卡片。**
  - 理由：一份技术文件有图、有表、有核对记录，不是一串面板模板。
  - 适用边界：通用排法也支持无图内容；本件作品按评审删除首屏圆顶缩略图，保留的八张简报图各出现一次，首屏光路示意与主镜图是两张不同图纸。

**网页排法。** 每个共享单元两种，全部是亮铝面；满版暗屏是作品片段，不是一种可以随意重复的排法。

| 单元 | 排法 | 说明 |
| --- | --- | --- |
| 首屏 | `tuzhi` 图纸 | 左侧标题与导语，右侧图纸，底部零件号与版次标题栏 |
| 首屏 | `mingpai` 铭牌 | 铭牌式标题在上，横向图纸在下，眉题与行动逐行排在铭牌里 |
| 问题 | `duizhao` 对照 | 左侧问题与正文，右侧用旧镜与新镜对照表核对口径、星等、接待厅和接待对象 |
| 问题 | `jianyan` 检验 | 问题标题横贯，正文与条目自上而下成一张检验单 |
| 方案 | `poumian` 剖面 | 左侧技术说明，右侧主镜剖面，图纸占主导 |
| 方案 | `zongtu` 总图 | 横向大图在上，图号与说明在下，留足铝面 |
| 特性 | `canshu` 参数 | 四列规格表：参数、右对齐数值、单位、技术说明；手机说明另占一行 |
| 特性 | `biaozhu` 标注 | 逐项标注栏，参数与说明合为一行，左侧保留标题栏 |
| 证据 | `jiance` 检测 | 左侧引述与署名，右侧读数核对表，合作方标识压在底部 |

| 流程 | `licheng` 历程 | 单条竖向基准线串起节点，说明跟在每个节点后 |

| 行动号召 | `qianfa` 签发 | 预约条件像文件签发栏，按键在最后一行靠左 |

| 页脚 | `banben` 版本 | 品牌、导航、法律说明纵向收尾，顶端两道切削边 |

### 形态

- 直角，包括铭牌按键。起点的 `key` 圆角在本网页取 0；不用圆角面板。
- 线有四种：图框粗线（墨，2px）、表格与尺寸界线（`rule`，1px）、网格（`rule-light`，1px，只在图纸区域）、倒角（`edge-hi` / `edge-lo`，1px，成对出现）。
- 段与段用 `alu-deep` 分隔带与亮暗成对的 1px 倒角形成独立铝面板；拉丝纹用最深 `ink`，透明度不超过 0.04。标题与关键读数用 `ink`，规格数值用 Inter 700 的 `head` 档（手机 `sub` 档），表头用 2px 墨线。
- 凸起件（铭牌、标题栏、按键）用 `alu-light` 底、四边倒角，可以投一道 `plate` 短影；平铺的面板没有影子。
- 不用卡片、不用胶囊按钮、不用图标库。尺寸线上的箭头、刻度端点只是图纸细节，不再构成第四个识别符号。

### 图像与画风

- **规则：画风是工程图与技术插图。** 墨色等宽细线、45° 剖面线、点划线的中心线、带箭头的尺寸标注、比例尺和图号。没有渐变、没有照片质感的金属反光。安全橙只指认一两处（光路、关键尺寸、关注点）。
  - 理由：图解是技术文件的一部分，可以核对而不是只提供气氛。
  - 适用边界：图上只标共享设定已给出的尺寸。光学结构、工作人员站位、路线转弯没有底图，明确标为示意，不补造焦距、顶灯尺寸或地理坐标；首屏采用卡塞格林示例结构（不宣称产品镜型），凹面主镜、凸面副镜与中心孔后的焦点必须符合反射几何。
- **优先画图纸而不是场景。** 剖面图、立面图、平面图、路线的纵断面、参数曲线，是本体系最有力的图像：它们本身就是数据。需要人物和现场时（如观测夜的访客），画成平面图上的站位和动线，或者用生图模型做成线稿式的技术插图（配方放 `images/src/prompts/`）。
- **素材来源。** 图纸用代码绘制（SVG），生成脚本放在本体系的 `images/src/`，用设定给出的尺寸（口径 1.6 米、厚约 200 毫米、圆顶直径 10 米、路线 38 公里、海拔 2,860 米）；不能把虚构设定称为真实测绘。不用图库照片。
- **图像在画面里的位置。** 图像是一张「图纸」：四周留铝面，下方有图号与说明；无底图时标示意而非印刷比例（等宽字）。同一件作品里不重复使用同一张图。

#### 无图方案

没有图像时，用三样东西撑起画面：刻度表盘、尺寸标注线、超大的等宽读数。读数用 Inter 700 放到 `display` 档以上，单位用等宽字；读数的数字落在 Inter 上，网格与标签只交代坐标，一个画面只有一个主角。

- **规则：无图时保留读数、单位、尺寸界线和版次，不画装饰性的假图。**
  - 理由：没有图像仍应是一份能核对的数据表。
  - 适用边界：没有参数时用标题与清单替代读数，不捏造数字。缺文案写 `【文案待定：参数说明】`。

### 识别符号

- 刻度表盘：一圈细密的刻度，读数弧和指针指向当前值；亮页用墨和安全橙，暗页用背光
- 尺寸标注线：两端带箭头和界线的细线，量出一段距离或一个数字
- 零件号与版次标签：等宽字的「KRO-1600 · REV.A」，刻在标题栏或铭牌上

## 动效语言

**性格：机加工与仪表。** 零件推入卡槽，到位即止；标注线一笔画出；仪表通电时读数弧逐格点亮。动效短、准、不回弹，像一台调校好的机器：没有多余的行程，也没有停下后的晃动。整体时长比纸本编辑短一档。

| 时长 | 数值（基准 40ms） | 用在 | 目的 |
| --- | --- | --- | --- |
| `tick` | 120ms | 悬停、按下的反馈，刻度逐格点亮的单格 | 反馈 |
| `snap` | 200ms | 透明度显现、小件到位 | 层级 |
| `slide` | 320ms | 零件推入、段落入场 | 导向 |
| `settle` | 480ms | 尺寸标注线画出、图纸显现 | 导向、层级 |
| `sweep` | 720ms | 读数弧扫过（暗页的高光） | 叙事 |

| 缓动 | 曲线 | 用在 |
| --- | --- | --- |
| `snap` | `cubic-bezier(.2, 0, 0, 1)` | 位移：推入、段落入场，起步快、收得硬 |
| `drive` | `cubic-bezier(.3, 0, .1, 1)` | 标注线、读数弧的画出：匀速驱动、到点即停 |
| `fade` | `cubic-bezier(.4, 0, .2, 1)` | 透明度 |
| `sweep` | `cubic-bezier(.65, 0, .35, 1)` | 读数弧扫过：起止都缓，像指针被驱动 |

**编排规则。**

- **规则：同组逐项错峰 `tick`（40ms）；主角先出，再出图纸和表格，标签最后。**
  - 理由：像零件推入卡槽，先定位再核对。默认位移 `slide` + `snap`（320ms），不超过 `space-2`（8px）；透明度默认 `snap` + `fade`（200ms），数值文件根部的 `entrance.opacity` 单独声明。
  - 适用边界：只向上或自左侧进入；每个列表显式递增名次。标注线用 `draw-x` / `draw-y`、`settle` + `drive`。无旋转、回弹、按下落定或悬浮常动。
- **规则：铭牌按键直角、细框、等宽标签，只在旁边留一个橙色指示点；悬停与聚焦时指示点亮、铭牌下沉 1px。**
  - 理由：行动像按机器上的刻印键，实心色块会把文件变成促销海报。
  - 适用边界：文字用 `ink`，背景用 `alu-light`，四边一亮一暗的倒角。悬停、键盘聚焦同样反馈，指示点用 `tick` + `fade`、位移用 `tick` + `snap`；减少动态效果移除下沉和反馈动画，保留指示点终态与聚焦轮廓。

### 高光时刻

- **规则：满版石墨屏中的冷青读数弧逐格显现，带真实刻度和指针，数字在表盘中心。**
  - 理由：仪表通电时，前面的尺寸与参数汇成一个读数；青色背光是整页唯一的高光。
  - 适用边界：普通标题、刻度底与说明最迟 320ms 完成；每格用 `data-ds-wait="settle"` 等 480ms 后才开始，再以 40ms 错峰、120ms 淡入，六格最后在 800ms 到位。中心数字与指针在同一等待后入场，透明度 200ms。亮面表盘保持静态。暗屏高度至少一个视口，只用石墨与背光组，不用安全橙。图纸数值是口径 1.6 米，不暗示刻度是产品测量上限。
- **规则：减少动态效果时去掉位移、额外等待和错峰，读数直接呈现终态，仅保留最短淡入。**
  - 理由：即使不播放装配过程，技术信息仍完整可读。
  - 适用边界：网页首屏、滚动入场和总览页重放；静态渲染直接显示所有图纸和读数。

## 结构骨架

只做网页，使用共享 `library/skeleton/web.json` 的八个单元：首屏、问题、方案、特性、证据、流程、行动号召、页脚；各提供两种排法，不增加本体系专属单元。不交付社交配图、幻灯片、PDF 或其排法和转场文件。

作品先以专属首屏建立 KRO-1600 产品数据表，问题、主镜图、参数表之后展开唯一暗屏，继以检测记录、施工工序、场址运输图与目镜观测图，最后签发预约铭板并用图栏结束。
