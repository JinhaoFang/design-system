# 预览导航与体系总览页 v2：设计原型

PR #55 审查反馈：导航页和体系总览页都是平铺长页，没有目录和折叠，体系总览页还出现「只有标题淡入、正文早就在」的怪动效。这里是设计负责人定稿的原型，实现照它做；实现与原型不一致时，以本文的规则为准。

## 怎么看原型

```bash
pnpm ds regress
mkdir -p out/regress/_proto && cp docs/design/preview-v2/{nav.html,system-v2.css,system-v2.js} out/regress/_proto/
cp -r .cache/fonts out/regress/_proto/fonts
python3 docs/design/preview-v2/make-system-proto.py paper-editorial riso-print
pnpm ds preview --dir out/regress
```

- 导航页：`http://127.0.0.1:4173/_proto/nav.html`（数据是写死的，实现时从产物读）。
- 体系总览页：`http://127.0.0.1:4173/<体系>/system/proto.html`。原型在浏览器里用脚本重排现有页面，实现时生成器要直接输出这个结构，不靠运行时改写 DOM。
- 两个宽度都要看：1440 和 390。

## 导航页（预览根路径 `/`）

导航页是工具界面，不用任何一套体系的样式：中性暖灰底色，Inter 加思源黑体（从本机字体缓存提供，不用子集化），跟随系统深浅色，并且可以手动切换。

1. **顶栏**（吸顶，56px，背景半透明加模糊）：左边是库名和「预览」；中间是各体系的跳转胶囊，每个胶囊前有一个色点，色点取该体系的强调色，滚动时高亮当前体系；右边是全部构建的错误和警告总数，绿、琥珀、红三种状态点，再加一个深浅色切换按钮。
2. **开头**：大标题「体系目录」，一句说明，右边是产物目录（太长时省略前段，悬停显示全路径）。
3. **每套体系一张卡片**，按 7:5 分两栏：
   - 左栏是封面：主网页样张的整页截图，裁成 16:10，顶部对齐。悬停或获得焦点时，截图在 7 秒内缓慢滚到底，等于预览了整页；减少动态效果时不滚动。点封面打开体系总览页。
   - 右栏依次是：编号和体系标识；体系名；材质锚点一句；色带，取数值文件里的颜色，底色和墨色画宽一些；调性迷你刻度，五对各五格；载体；检查结果；两个按钮，主按钮「打开体系总览 →」，次按钮「排法总览」加件数。
4. **体系样张**：可折叠，默认展开。卡片统一高度（桌面 176px，手机 144px），宽度按各载体原始比例算：幻灯片 16:9，社交配图 3:4、1:1、2.35:1，原样显示、不裁切；网页截取顶部。卡片下方写作品名、错误和警告状态、载体与画幅。超出一行就横向滚动。
5. **检查报告**：可折叠，默认收起。标题行写报告份数和合计，展开后是一张表：构建、载体、错误、警告、报告链接，体系总览页也列在里面。
6. **折叠状态和深浅色**记在 `localStorage` 里，读写都包在 try/catch 中；读不到时用默认值。
7. **排法总览列表页**（`/_overview/<体系>/overview/`）用同一套外观：顶栏加返回；按载体和画幅分组，每组可以折叠，组标题写件数和警告数；缩略图按原始比例完整显示（现在公众号封面被裁掉了一大半）；可以筛选「只看有警告」。
8. **动效**：载入时，开头和每张体系卡片依次上浮淡入，位移 14px、时长 800ms、错峰 70ms，缓动 `cubic-bezier(.2,.65,.15,1)`。按钮悬停时箭头右移 3px，样张卡片悬停时上浮 3px，折叠展开用 `grid-template-rows` 过渡，时长 800ms。减少动态效果时全部取消。

## 体系总览页（`<体系>/system/`）

体系总览页仍然完全用体系自己的数值排版：颜色、字体、字阶、间距、时长和缓动都取自体系，原有的检查器约束不变。原型里新增的样式也只用 `--ds-*` 变量。

1. **布局**：宽度 ≥1180px 时分两栏，左边是 14rem 宽的目录栏，右边是正文。体系自己的页头仍然横跨整页。原来的顶部锚点条去掉。
2. **目录栏**（吸顶，高一屏）：
   - 「<体系名> · 目录」下面一条墨线；各节写编号加标题。当前节用墨色，其余用次级墨色。
   - 目录左侧有一条发丝线，上面有一段 2px 的墨色滑块，跟着当前节移动。滑块的移动和高度变化用体系的 `ink` 档时长和 `paper` 缓动（按阶梯位置取：中档时长、第一条缓动）。这是这一页的标志性动效。
   - 当前节如果有小节标题（`h3.sp-sub`），在它下面展开小节目录；排法这一节改用页签，不列小节。
   - 底部依次是：阅读进度线、「全部收起 / 全部展开」、「减少动态效果」（和动效一节里的开关同步）、返回预览导航、排法总览的链接。
3. **窄屏**（<1180px）：不显示目录栏。改成吸顶条，左边写体系名加当前节的编号和标题，右边是「目录」按钮，底边是进度线。点「目录」从顶部滑出全屏目录，每节后面附上它的计数；点任一节或按 Esc 关闭。
4. **节标题**：整行是一个按钮，`aria-expanded` 写明展开状态，按钮里依次是编号、标题、计数和展开符号（加号竖线旋转成减号）。各节的计数：意图写关键规则条数；样张写样张件数和范例件数；排法写叙事单元数和排法数；色彩写颜色数和组数；字体写字体数；字阶写字阶档数和间距档数；动效写演示个数。默认全部展开，折叠状态按体系记在 `localStorage` 里。点目录里收起的节时自动展开；地址里的锚点也会让对应的节展开。
5. **折叠动画**：`grid-template-rows` 从 1fr 过渡到 0fr，用 `glide` 档时长和 `paper` 缓动，内容同时淡出。收起后，节标题下面显示一行「已收起，点标题展开」。
6. **排法**：按载体分页签，顺序是网页、幻灯片、社交配图，每个页签写排法数。页签下面有一条 2px 的指示线，在页签之间滑动。默认选中网页，记住上次的选择，可以用方向键切换。只有一种载体时不显示页签。每种排法都要有缩略图：网页排法目前没有图（孔版印刷整节都是纯文字），要从排法总览的网页构建里，截取该单元所在的那一段。
7. **长表格**：超过 6 行的表格（色值与用途表、各节的 SYSTEM.md 表格）收进「<表名> · N 行」折叠条，默认收起。
8. **体系样张一节**：标题从「标准样张与范例」改为「体系样张与范例」。
9. **色彩**：手机宽度下，每个色块改成一行，左边是色块，右边是名称和色值，不再挤成四列。
10. **动效**：节标题和正文不加滚动入场，这正是现在「只有标题淡入」问题的来源。滚动入场整页只留在体系页头。其余动效都是对操作的反馈：目录滑块、页签指示线、折叠、展开符号旋转、全屏目录滑出。减少动态效果开启时（系统设置或页面开关），这些过渡全部瞬时完成。
11. **静态渲染**（截图和检查时的 `html[data-render="static"]`）：所有节、折叠条、页签面板都展开显示，确保检查器检查到全部内容，截图里也能看全。

## 验收看什么

- 两套体系各自在 1440 和 390 下的体系总览页：目录滑块跟随，折叠和展开顺滑，页签可用，没有横向滚动。
- 导航页在浅色和深色下各看一遍，样张卡片没有被裁掉的。
- 录屏一段：滚动体系总览页，看目录滑块的手感，并且确认没有任何「标题单独淡入」。
