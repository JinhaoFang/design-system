# 文档地图

| 文档 | 内容 |
|---|---|
| `../AGENTS.md` | 共同规则、角色、目录与归属（两个 agent 每次都会读） |
| `roadmap.md` | 目标、已定的决策、进度和下一步，**新会话从这里看起** |
| `plan.md` | 方案 v0.3：美学立场、体系模型、需求翻译、产出流程、提取、系统构成、路线 |
| `cli.md` | `pnpm ds` 各命令的用法、产物和格式约定 |
| `workflow/README.md` | 开发工作流：生命周期、执行回路、什么放在哪里、技能放在哪里、护栏、图像与评审、路线图的写法 |
| `roles/design.md` | 设计负责人：自己做和派出去的判断标准、验收方法 |
| `roles/engineering.md` | 工程负责人：硬规则、可用技能、完成标准、汇报格式 |
| `agents/issue-tracker.md` | GitHub 工单的操作方法和本仓库的工单约定 |
| `agents/run-spec.md`、`agents/run-spec.json` | 执行技能的本仓库配置 |
| `agents/triage-labels.md`、`agents/domain.md` | Matt 技能的标签表、术语文档布局 |
| `adr/` | 架构决策记录 |
| `../GLOSSARY.md` | 术语表 |
| `../library/craft.md` | 工艺规范 |

每个 spec 完成后，设计负责人给用户的工作汇报放在 `reports/`。
