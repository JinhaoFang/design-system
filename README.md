# design-system

面向 AI Agent 的设计体系库：收录成套、有设计感的设计体系，让 agent 直接用它们产出网页、PPT、图片等成品，也能从参考样例中提取设计体系再复用。

> 状态：第 0 阶段（打地基）进行中。构建并检查流程、检查器和库数据已经可用，第一套种子体系「纸本编辑」正在做。
